# PPT 高手之路

## 1. 原来 PPT 的默认设置这么好用

这一节讲的是正式开始做 PPT 前，应该先调整哪些软件默认设置。很多功能不是不会用，而是默认没有打开；把这些设置提前配置好，后面做页面、处理图片、导出文件和跨电脑播放都会顺很多。

### 1.1 推荐使用的 Office 版本

课程建议优先使用微软 Office，而不是旧版 Office 或 WPS。

推荐版本：

- Microsoft Office 2013 及以上版本
- Office 2016
- Office 2019
- Microsoft 365

不推荐版本：

- Office 2003
- Office 2007
- Office 2010
- WPS 作为课程学习环境

这里的核心理由不是“旧版不能用”，而是新版 PowerPoint 的功能更完整。很多课程中会用到的高级功能、动画能力、图片处理能力和默认设置项，在旧版 Office 或 WPS 中可能不存在，或者实现不够完善。

查看 Office 版本的方法：

1. 打开 PowerPoint
2. 点击“文件”
3. 进入“账户”
4. 查看右侧的产品名称

如果显示的是 `Microsoft 365`，说明当前软件会持续获得新功能更新。如果显示的是 `Office 2013`、`Office 2016` 或 `Office 2019`，则属于固定版本。

### 1.2 打开更适合长时间工作的主题

PowerPoint 支持修改界面主题。这个设置影响的是软件界面，不影响幻灯片内容本身。

设置路径：

```text
文件 -> 账户 -> Office 主题
```

常见主题包括：

- 彩色
- 白色
- 深灰色
- 黑色

如果经常在晚上做 PPT，可以尝试使用“深灰色”或“黑色”主题。深色界面会降低屏幕刺激，长时间编辑时更舒服。

`Office 背景` 只会改变右上角的小图案，对工作效率没有实质影响，可以不重点关注。

### 1.3 将撤销次数调到最大

PowerPoint 默认撤销次数较少，课程中提到默认大约是 `20` 次。做复杂页面时，这个数量不够用。

设置路径：

```text
文件 -> 选项 -> 高级 -> 最多可取消操作数
```

推荐设置：

```text
150
```

`150` 是 PowerPoint 允许设置的最大撤销次数。调整后，如果误删元素、误改版式或重复尝试效果，就有更大的回退空间。

### 1.4 设置自动恢复保存

做 PPT 时最怕软件卡死、电脑没电或系统崩溃。自动恢复保存可以降低丢失进度的风险。

设置路径：

```text
文件 -> 选项 -> 保存 -> 保存自动恢复信息时间间隔
```

推荐设置：

```text
5 分钟
```

PowerPoint 会把自动恢复文件保存到本地路径。可以在同一个设置页面中找到“自动恢复文件位置”，复制路径后在文件资源管理器中打开。

左上角的“自动保存”通常需要配合 OneDrive 和正版账户使用。如果只是希望降低本地文件丢失风险，设置“保存自动恢复信息时间间隔”更直接。

### 1.5 关闭图片自动压缩

PowerPoint 默认可能会压缩插入的图片。这样文件会变小，但图片清晰度可能下降。

课程中演示了一个判断方法：将 `.pptx` 后缀改为压缩包格式并解压，可以在 `ppt/media` 目录中看到插入图片的真实大小。如果没有关闭压缩，原本几 MB 的图片可能被压到更小。

设置路径：

```text
文件 -> 选项 -> 高级 -> 图片大小和质量
```

推荐设置：

1. 勾选“不压缩文件中的图像”
2. 默认分辨率选择“高保真”

这个设置适合对图片质量有要求的 PPT，尤其是封面图、产品图、人物图和全图背景。

### 1.6 将字体嵌入文件

如果 PPT 使用了特殊字体，而另一台电脑没有安装该字体，打开文件时字体就会丢失。字体嵌入可以缓解这个问题。

设置路径：

```text
文件 -> 选项 -> 保存 -> 将字体嵌入文件
```

推荐选项：

```text
仅嵌入演示文稿中使用的字符
```

这样可以让 PPT 在其他电脑上尽量保持原来的字体效果，同时避免文件体积过度膨胀。

需要注意的是，并不是所有字体都允许嵌入。如果字体授权限制嵌入，仍然可能无法完整保留效果。

### 1.7 学会多格式导出

PowerPoint 不只能保存为 `.pptx`，还可以导出为多种格式。

常见导出类型：

- PDF
- PNG 图片
- 图片型 PowerPoint
- 视频

导出 PDF：

```text
文件 -> 导出 -> 创建 PDF/XPS 文档
```

PDF 适合商业传输、资料发送和定稿展示。对方无需安装 PowerPoint，也能稳定查看页面效果。

导出图片：

```text
文件 -> 另存为 -> PNG
```

可以将每一页幻灯片导出为图片，适合用于文章配图、社交媒体发布或截图式展示。

导出图片型 PowerPoint：

```text
文件 -> 另存为 -> PowerPoint 图片演示文稿
```

这种文件仍然是 PPT，但每一页内容会变成图片。它适合防止版式错乱，也能降低别人直接修改页面元素的可能。

导出视频：

```text
文件 -> 导出 -> 创建视频
```

导出视频时，可以设置分辨率和每张幻灯片的播放秒数。如果 PPT 中设置了切换或动画，导出后也会体现在视频中。

### 1.8 打开参考线辅助对齐

参考线适合用来控制页面中的固定位置，例如 Logo、标题、安全边距和版心区域。

设置路径：

```text
视图 -> 标尺 / 网格线 / 参考线
```

常用操作：

- 勾选“标尺”
- 勾选“网格线”
- 勾选“参考线”
- 按住 `Ctrl` 拖动参考线，可以复制新的参考线
- 右键参考线，可以添加或删除垂直、水平参考线

参考线会帮助你在不同页面之间保持统一位置。比如每页右上角都需要放 Logo，就可以用参考线固定 Logo 的对齐位置。

### 1.9 设置默认字体

PowerPoint 默认字体不一定适合中文 PPT。每次插入文本框后再手动改字体，会浪费大量时间。

设置路径：

```text
设计 -> 变体 -> 字体 -> 自定义字体
```

可以分别设置：

- 中文标题字体
- 中文正文字体
- 西文标题字体
- 西文正文字体

课程中推荐将中文标题和正文都改成更常用的字体，例如微软雅黑。设置完成后，新建文本框会自动使用指定字体。

### 1.10 设置默认形状样式

PowerPoint 默认插入的形状通常是蓝色填充并带边框。这个样式不一定适合实际设计。

设置默认形状的方法：

1. 插入一个形状
2. 设置填充颜色
3. 设置轮廓颜色
4. 设置轮廓粗细
5. 右键该形状
6. 选择“设置为默认形状”

设置后，再插入矩形、圆形、三角形等形状时，都会沿用这个默认样式。

这个功能适合在一个项目开始前统一图形风格，减少重复设置。

### 1.11 清除默认占位符

新建幻灯片时，PowerPoint 默认会出现标题和内容占位符。如果你习惯自己设计页面，这些占位符经常需要手动删除。

处理方法：

```text
视图 -> 幻灯片母版
```

操作步骤：

1. 进入“幻灯片母版”
2. 找到当前使用的版式
3. 选中默认占位符
4. 删除这些占位符
5. 关闭母版视图

处理后，新建页面时就不会再出现多余的默认占位符。

### 1.12 本节总结

这一节主要讲两件事：先选对 Office 版本，再把常用默认设置调好。

推荐设置包括：

- 使用 Microsoft Office 2013 及以上版本
- 使用深灰色或黑色主题
- 将撤销次数设置为 `150`
- 将自动恢复保存间隔设置为 `5 分钟`
- 关闭图片自动压缩
- 将字体嵌入文件
- 掌握 PDF、图片、图片型 PPT 和视频导出
- 打开标尺、网格线和参考线
- 设置默认字体
- 设置默认形状样式
- 清除默认占位符

这些设置不直接决定设计水平，但会明显减少重复劳动和意外损失。先把软件环境调顺，再开始做页面，后面的 PPT 制作会更稳定。

## 2. 掌握好这些 PPT 快捷键

这一节讲的是 PPT 操作姿势。做 PPT 时，右手负责鼠标，左手不应该闲着，而是要放在 `Ctrl`、`Shift`、`Alt` 这些按键附近。很多高频操作只靠鼠标会很慢，熟悉快捷键后，排版、复制、缩放、旋转和文本处理都会明显提速。

### 2.1 `Shift` 家族

`Shift` 主要用于“约束规则”。它可以让移动、缩放、绘制和旋转变得更规整。

#### 2.1.1 水平或垂直移动

移动元素时按住 `Shift`，元素只会沿水平或垂直方向移动。

适用场景：

- 将对象横向移动到另一侧
- 将对象垂直移动到下方
- 避免拖动时产生轻微偏移
- 保持元素与原位置在同一水平线或垂直线上

这个功能适合做整齐排版。不要依赖肉眼判断“差不多水平”，而是用 `Shift` 锁定移动方向。

#### 2.1.2 等比例缩放

缩放图片或形状时按住 `Shift`，对象会按照原比例放大或缩小。

如果不按 `Shift`，正方形可能被拉成长方形，圆形可能被拉成椭圆，图片也可能被挤压变形。

常见用途：

- 保持正方形比例
- 保持圆形比例
- 保持图片原始比例
- 保持图标不变形

#### 2.1.3 绘制规则形状

插入形状时按住 `Shift`，可以绘制规则形状。

例如：

- 绘制正方形
- 绘制正圆
- 绘制等比例三角形

还有一种方法是选择形状后直接单击页面，而不是拖拽绘制。直接单击生成的形状通常会保持默认比例。

#### 2.1.4 按固定角度旋转

旋转对象时按住 `Shift`，可以按固定角度旋转。课程中强调的是每次旋转约 `15°`，适合做规整角度。

适用场景：

- 旋转 `15°`
- 旋转 `30°`
- 旋转 `45°`
- 旋转 `90°`

如果需要精确角度，也可以在“设置形状格式”中输入具体旋转数值。

### 2.2 `Ctrl` 家族

`Ctrl` 主要用于复制、缩放、组合、保存和撤销。它是 PPT 中最常用的一组快捷键。

#### 2.2.1 快速缩放画布

按住 `Ctrl` 并滚动鼠标滚轮，可以快速放大或缩小当前页面视图。

这个操作影响的是编辑视图，不影响页面内容本身。

适用场景：

- 放大局部细节
- 检查对象边缘
- 调整小图标
- 快速回到整体页面

#### 2.2.2 拖拽复制

按住 `Ctrl` 拖动对象，可以快速复制对象。

对比常规复制：

```text
Ctrl + C -> Ctrl + V
```

拖拽复制更适合在页面上直接复制并摆放对象：

```text
Ctrl + 鼠标拖拽
```

它的优势是复制和定位可以同时完成。

#### 2.2.3 快速复制

`Ctrl + D` 可以快速复制对象。

它不只是复制元素本身，还会记住上一次复制后的距离和方向。调整第二个对象的位置后，继续按 `Ctrl + D`，后续对象会按照同样的距离和方向继续生成。

典型用途：

- 制作等距排列
- 制作点阵背景
- 制作纹理图案
- 制作规律重复元素

操作逻辑是：

```text
复制一个对象 -> 调整第二个对象的位置 -> 连续按 Ctrl + D
```

#### 2.2.4 新建页面

新建幻灯片可以使用：

```text
Ctrl + M
```

如果当前已经选中左侧缩略图，也可以直接按 `Enter` 新建页面。

#### 2.2.5 组合对象

`Ctrl + G` 可以组合多个对象。

组合后的对象会被视为一个整体，适合统一移动、缩放和旋转。

组合的价值在于：多个对象之间的相对位置可以被保留下来。比如两个形状之间有固定距离，组合后整体缩放时，这个距离关系也会一起变化。

#### 2.2.6 保存、撤销和恢复

常用快捷键：

- `Ctrl + S`：保存
- `Ctrl + Z`：撤销
- `Ctrl + Y`：恢复

`Ctrl + S` 应该形成习惯，尤其是在做复杂页面、长时间编辑或电脑不稳定时。

### 2.3 `Ctrl + Shift` 组合

`Ctrl` 和 `Shift` 单独使用已经很有用，组合起来后可以同时具备复制和规则约束能力。

#### 2.3.1 水平或垂直移动复制

按住 `Ctrl + Shift` 拖动对象，可以实现水平或垂直方向的复制。

作用拆解：

- `Ctrl`：复制
- `Shift`：限制水平或垂直方向

适用场景：

- 横向复制按钮
- 纵向复制列表项
- 制作整齐阵列
- 保持复制对象与原对象对齐

#### 2.3.2 等比例中心缩放

课程中提到，单独按 `Shift` 缩放时，对象会从某个角向另一个方向变化，中心点可能移动。

如果想让对象保持中心不动，并且等比例放大或缩小，可以使用：

```text
Ctrl + Shift + Alt + 拖动控制点
```

这个组合适合处理需要保持中心位置的图标、圆形、装饰元素和背景形状。

#### 2.3.3 复制和粘贴格式

复制格式：

```text
Ctrl + Shift + C
```

粘贴格式：

```text
Ctrl + Shift + V
```

它相当于键盘版格式刷，可以快速复制一个对象的填充色、轮廓、线条粗细等格式。

使用流程：

1. 选中已有格式的对象
2. 按 `Ctrl + Shift + C`
3. 选中目标对象
4. 按 `Ctrl + Shift + V`

这个功能适合统一多个形状的视觉风格。

#### 2.3.4 解除组合

组合对象：

```text
Ctrl + G
```

解除组合：

```text
Ctrl + Shift + G
```

很多快捷键中，`Ctrl` 用于应用某个功能，`Ctrl + Shift` 用于解除或反向操作。组合和解除组合就是典型例子。

### 2.4 文本框快捷键

文字处理是 PPT 中的高频操作。使用快捷键可以减少频繁点击工具栏。

#### 2.4.1 快速生成占位文字

在文本框中输入：

```text
=LOREM()
```

然后按回车，可以生成一段占位文字。

这类文字没有真实含义，主要用于测试排版效果。

#### 2.4.2 调整字号

选中文字后，可以用快捷键调整字号：

- `Ctrl + ]`：放大字号
- `Ctrl + [`：缩小字号

这个操作比去工具栏点击字号更快，适合微调文本大小。

#### 2.4.3 加粗、斜体和下划线

常用文字格式快捷键：

- `Ctrl + B`：加粗
- `Ctrl + I`：斜体
- `Ctrl + U`：下划线

这些快捷键在 Word、Excel、PowerPoint 中都很常见。

#### 2.4.4 文本对齐

常用对齐快捷键：

- `Ctrl + E`：居中对齐
- `Ctrl + L`：左对齐
- `Ctrl + R`：右对齐

记忆方式：

- `L` 对应 `Left`
- `R` 对应 `Right`
- `E` 对应居中对齐

### 2.5 `Alt` 菜单序列

`Alt` 可以调用 PowerPoint 的菜单快捷路径。它不是同时按多个键，而是按顺序输入一串键。

课程中特别强调两个序列：

```text
Alt -> N -> X -> H
```

作用是快速插入文本框。

```text
Alt -> N -> P -> D
```

作用是快速插入图片。

这里的箭头表示按键顺序，不是同时按下。先按 `Alt`，界面上会显示各个菜单对应的字母提示，再依次按后续字母。

如果经常插入文本和图片，这两个序列值得刻意练习。

### 2.6 本节总结

这一节的核心是：做 PPT 不能只靠鼠标，左手要参与操作。

重点快捷键包括：

- `Shift + 拖动`：水平或垂直移动
- `Shift + 缩放`：等比例放大或缩小
- `Shift + 绘制形状`：绘制规则形状
- `Shift + 旋转`：按固定角度旋转
- `Ctrl + 鼠标滚轮`：快速缩放画布
- `Ctrl + 拖动`：拖拽复制
- `Ctrl + D`：快速复制并延续距离
- `Ctrl + M`：新建页面
- `Ctrl + G`：组合
- `Ctrl + S`：保存
- `Ctrl + Z`：撤销
- `Ctrl + Y`：恢复
- `Ctrl + Shift + 拖动`：水平或垂直移动复制
- `Ctrl + Shift + C`：复制格式
- `Ctrl + Shift + V`：粘贴格式
- `Ctrl + Shift + G`：解除组合
- `Ctrl + B`：加粗
- `Ctrl + I`：斜体
- `Ctrl + U`：下划线
- `Ctrl + E`：居中对齐
- `Ctrl + L`：左对齐
- `Ctrl + R`：右对齐
- `Alt -> N -> X -> H`：插入文本框
- `Alt -> N -> P -> D`：插入图片

快捷键不是为了炫技，而是为了减少重复点击。把这些操作练熟后，PPT 制作会从“慢慢点工具栏”变成“键盘和鼠标协同完成”。

## 3. PPT 合并形状到底有多好用

这一节讲的是 PowerPoint 中的“合并形状”。它是区分 PPT 新手和进阶使用者的重要功能：新手通常只会使用默认形状，进阶使用者会把多个基础形状组合、切割、相交，生成自己真正需要的形状。

### 3.1 为什么合并形状重要

PowerPoint 自带了大量默认形状，例如矩形、圆形、三角形、箭头、流程图形状等。随着版本升级，默认形状也在不断增加。

但默认形状并不能解决所有设计需求。例如一个“圆角五边形”，看起来并不复杂，但 PowerPoint 默认形状里并没有现成选项。

这时就需要合并形状：

- 默认形状是素材库
- 合并形状是造型工具
- 默认形状数量有限
- 组合后的形状数量接近无限

很多看起来像文字、图标、图表的元素，本质上也可以变成形状。形状的优势是可以自由填充、设置轮廓、缩放，并且放大后不会失真。

### 3.2 合并形状的位置

合并形状位于：

```text
形状格式 -> 插入形状 -> 合并形状
```

需要先选中两个或多个形状，才会看到相关命令。

合并形状主要包括五个功能：

- 结合
- 组合
- 拆分
- 相交
- 剪除

这些功能本质上类似数学中的布尔运算，用来处理形状之间的并集、差集、交集和分割关系。

### 3.3 五种合并形状功能

#### 3.3.1 结合

“结合”会把多个形状合成一个整体，保留所有形状覆盖到的区域。

可以理解为：

```text
形状 A + 形状 B -> 一个新形状
```

适合把多个基础形状拼成一个完整图形。

#### 3.3.2 组合

“组合”会去掉多个形状重叠的部分，只保留没有重叠的区域。

它和普通的 `Ctrl + G` 组合不同。普通组合只是把对象打包在一起，而“合并形状”里的组合会真正改变形状结构。

适合制作镂空效果。

#### 3.3.3 拆分

“拆分”会把重叠区域和不重叠区域全部切开，变成多个独立部分。

例如一个圆和一个矩形重叠后进行拆分，可能得到：

- 圆形未重叠部分
- 矩形未重叠部分
- 中间重叠部分

拆分适合从复杂交叠中取出某个局部区域。

#### 3.3.4 相交

“相交”只保留多个形状共同重叠的区域。

可以理解为：

```text
只留下交集
```

适合做局部裁切、特殊边缘和两个形状交汇处的区域。

#### 3.3.5 剪除

“剪除”会用后选中的形状去减掉先选中的形状中的重叠部分。

这里有一个关键原则：

```text
先点击的最后保留
```

也就是说，选择顺序会影响结果。先选择黑色矩形，再选择红色圆形并执行剪除，最后保留的是矩形被圆形挖掉后的结果；如果先选择圆形，再选择矩形，结果就会反过来。

### 3.4 用合并形状制作复杂图形

合并形状可以用来制作默认形状库里没有的图形。

例如制作一个带圆弧边和直线边的特殊形状，可以先用圆和矩形叠加，再通过“拆分”或“相交”取出需要的区域。

基本思路是：

1. 先判断目标图形由哪些基础形状构成
2. 用圆、矩形、多边形等搭出大致轮廓
3. 用对齐工具保证位置准确
4. 使用结合、相交、拆分或剪除得到目标区域
5. 删除多余部分
6. 统一填充和轮廓

这个思路比单纯寻找默认形状更灵活。

### 3.5 用合并形状绘制图标

合并形状最常见的用途之一是绘制图标。

图标的作用是让页面内容更容易被理解。相比纯文字，图标可以快速传达含义，让观众更快抓住重点。

图标来源可以有两种：

- 自己用合并形状绘制
- 从图标库下载 `SVG` 图标并插入 PPT

如果自己绘制图标，可以将圆形、矩形、圆角矩形等基础形状进行合并和剪除。

例如课程中的煎蛋图标，核心由多个圆形和圆角矩形构成：

- 用圆形制作蛋白区域
- 用圆形制作蛋黄
- 用剪除制作蛋黄阴影
- 用圆角矩形制作局部装饰
- 最后组合并添加阴影

这种做法的重点不是记住某个案例，而是理解：复杂图标通常可以拆解成多个简单形状。

### 3.6 将文字转换为形状

文字也可以转换为形状。转换后，它不再是可编辑文字，而是可以像图形一样填充、剪除、拆分和缩放。

文字转形状的好处：

- 避免字体丢失
- 保留特殊字体效果
- 可以对文字做形状运算
- 可以拆分文字笔画
- 方便做创意字效

课程中讲了两种方式。

第一种方式是快速整体转换：

1. 插入文字
2. 在文字旁边绘制一个形状
3. 先选中文字
4. 再选中形状
5. 使用“剪除”

这样可以把文字整体转换为形状。

第二种方式是拆分笔画：

1. 插入文字
2. 绘制一个比文字更大的形状
3. 同时选中文字和形状
4. 使用“拆分”

这种方式可以把文字拆得更细，适合做更复杂的文字设计。

### 3.7 将图表转换为形状

图表也可以转换为形状。转换后，图表不再跟数据联动，但可以获得更自由的设计控制。

适用场景：

- 想旋转图表
- 想翻转图表
- 想单独修改图表某一部分
- 想做更自由的图表设计
- 不再需要数据动态更新

操作流程：

1. 选中图表
2. 右键选择“另存为图片”
3. 保存类型选择 `增强型 Windows 图元文件`
4. 插入保存后的 `EMF` 文件
5. 右键选择“组合 -> 取消组合”
6. 必要时再次取消组合

完成后，图表会被拆成多个可编辑形状。这样就可以对它进行旋转、翻转、填充和局部设计。

需要注意的是，图表变成形状后就不再是数据图表，不能继续通过数据表更新数值。

### 3.8 本节总结

合并形状的核心价值是把有限的默认形状扩展成无限的自定义形状。

五个功能需要重点掌握：

- 结合：保留所有形状区域
- 组合：去掉重叠区域，保留未重叠区域
- 拆分：把重叠和未重叠区域全部切开
- 相交：只保留重叠区域
- 剪除：用后选对象减掉先选对象，先点击的最后保留

合并形状的常见用途有三类：

- 绘制图标和自定义素材
- 将文字转换为形状，避免字体丢失
- 将图表转换为形状，获得更自由的设计能力

学会合并形状后，PPT 就不再局限于默认形状库。你可以用基础形状搭出需要的图标、装饰、文字效果和复杂版式。

## 4. 三招设计高质感 PPT 表格

这一节讲的是 PPT 表格设计。表格看起来复杂，但在页面设计中反而是比较容易做出专业感的一类内容。关键不是堆效果，而是理解表格独立的操作逻辑，并掌握底纹、框线和单元格这三个核心设置。

### 4.1 为什么表格不好学

PPT 表格和普通形状的操作逻辑不一样。

普通形状的操作比较直接：

- 点击形状
- 修改填充
- 修改轮廓
- 旋转或缩放

但表格不是这样。选中表格后，如果直接修改填充，可能修改的是整个表格背景，而不是你想改的某一列、某一行或某个单元格。

表格难学主要有三个原因：

- 表格是一个相对独立的功能模块
- 表格和图表类型很多，各自有独特设置
- 市面上专门讲 PPT 表格和图表设计的内容较少

所以学习表格时，不能完全套用“形状怎么改，表格也怎么改”的思路，而要单独理解它的结构。

### 4.2 去哪里看优秀表格

如果想提高表格审美，可以多看商业报告和数据新闻。

课程中提到的参考来源包括：

- 麦肯锡中国
- 第一财经
- 网易数读
- 财经网数据新闻
- 国双数据报告
- 上市公司年报
- 企业社会责任报告

这些材料中常见大量专业报表、信息图和数据可视化页面。看这些案例时，不只是看配色，还要看它们如何处理标题行、内容行、边框、间距和数据层级。

### 4.3 表格的核心功能

PPT 表格中需要优先掌握三个功能：

1. 底纹
2. 框线
3. 单元格

这三个功能掌握后，大多数表格美化都可以完成。

### 4.4 底纹

底纹可以理解为表格单元格的填充颜色。

设置位置：

```text
表设计 -> 底纹
```

表格和普通形状不同，表格由多个独立单元格组成。你选中哪一行、哪一列或哪几个单元格，底纹就会作用到对应区域。

#### 4.4.1 快速选中行和列

不要用鼠标一点点拖拽选择整行或整列，表格很大时效率会很低。

快速选中一行：

1. 将鼠标移到表格左侧边缘
2. 等光标变成向右箭头
3. 单击即可选中整行

快速选中一列：

1. 将鼠标移到表格顶部边缘
2. 等光标变成向下箭头
3. 单击即可选中整列

选中后就可以统一修改底纹。

#### 4.4.2 用表格制作九宫格图片

表格还可以用来做九宫格图片效果。

基本流程：

1. 插入 `3 x 3` 表格
2. 调整为接近正方形的区域
3. 选中所有单元格
4. 打开“设置形状格式”
5. 选择“图片或纹理填充”
6. 从剪贴板或文件插入图片
7. 勾选“将图片平铺为纹理”
8. 调整为居中对齐

如果要把九宫格真正拆成多张图片，可以继续：

1. 右键表格
2. 选择“另存为图片”
3. 保存类型选择 `增强型 Windows 图元文件`
4. 重新插入该 `EMF` 文件
5. 右键选择“组合 -> 取消组合”
6. 必要时再次取消组合

这样就可以将一张图片拆成九个独立图片块，再做拼图式排版。

### 4.5 框线

框线可以理解为表格的边框，但它比普通形状边框更复杂。因为表格中有外框线、内框线、横框线、竖框线、斜上框线、斜下框线等不同类型。

设置位置：

```text
表设计 -> 绘制边框
```

常用设置包括：

- 笔颜色
- 线条粗细
- 线条样式

设置好笔颜色和粗细后，可以用小铅笔直接绘制框线。但更高效的方法是使用“边框”下拉菜单。

常用边框选项包括：

- 所有框线
- 外侧框线
- 内部框线
- 内部横框线
- 内部竖框线
- 上框线
- 下框线
- 左框线
- 右框线
- 无框线
- 斜上框线
- 斜下框线

如果要快速统一某一片区域的线条，先选中目标单元格，再通过边框菜单批量应用，比手动画线更快。

### 4.6 单元格

表格中的单元格不能像普通对象一样单独删除。

如果看起来某个单元格被“删掉”了，本质上通常只是：

- 底纹设置为无填充
- 框线设置为无框线
- 单元格里不放文字

真正能改变单元格结构的操作主要是：

- 合并单元格
- 拆分单元格

#### 4.6.1 合并单元格

合并单元格可以把多个单元格合成一个区域。

操作步骤：

1. 选中多个相邻单元格
2. 打开“布局”
3. 点击“合并单元格”

合并后，只能在合并后的大单元格中输入内容。

#### 4.6.2 拆分单元格

拆分单元格可以把一个单元格重新拆成多行多列。

操作步骤：

1. 选中目标单元格
2. 打开“布局”
3. 点击“拆分单元格”
4. 输入要拆成的行数和列数

比如要恢复成 `3` 列 `2` 行，就在拆分设置中输入对应数值。

### 4.7 表格美化三招

课程中给出了最实用的表格美化方法。只要掌握三招，就可以把很普通甚至很丑的表格改得更专业。

#### 4.7.1 标题行使用主题色

第一步是处理标题行。

操作思路：

1. 选中表格第一行
2. 使用底纹填充主题色
3. 主题色可以从 Logo 或品牌色中取色
4. 将标题文字改成白色
5. 根据需要加粗

标题行是表格的视觉入口。使用主题色可以让表格和页面整体风格保持一致。

#### 4.7.2 内容行颜色交替

第二步是处理内容行。

内容行可以使用浅色交替：

- 一行白色
- 一行极浅的主题色
- 再一行白色
- 再一行极浅的主题色

浅色交替能帮助读者横向阅读数据，也能避免大块内容显得混乱。

浅色可以从主题色中调出来：保留色相，但把颜色调到非常接近白色的位置。

#### 4.7.3 内框线虚化，外框线加粗

第三步是处理框线。

处理原则：

- 内框线要轻
- 外框线要稳
- 不要让所有线条都一样粗

常见做法：

1. 选中整个表格
2. 将内部框线设置为浅灰色
3. 内部框线粗细设置较细
4. 将外侧框线设置为更深颜色
5. 外侧框线适当加粗

这样表格会有层次：内部信息不被线条干扰，外部轮廓又足够清晰。

### 4.8 本节总结

表格设计并不难，难点在于它的操作逻辑和普通形状不同。

需要掌握的三个核心功能是：

- 底纹
- 框线
- 单元格

表格美化的三招是：

- 标题行使用主题色
- 内容行颜色交替
- 内框线虚化，外框线加粗

如果再配合合适字体、统一对齐和适当留白，普通表格也可以快速变得专业。

## 5. PPT 编辑顶点的 N 种快乐玩法

编辑顶点和合并形状是一组非常重要的 PPT 矢量绘图能力。

- 合并形状负责多个形状之间的组合
- 编辑顶点负责单个形状内部的变形

如果说合并形状解决的是“多个形状怎么合成新形状”，那么编辑顶点解决的就是“一个形状怎么改成自己想要的样子”。

### 5.1 编辑顶点是什么

普通拖拽控点只能改变形状的大小比例，例如把圆变成椭圆、正方形变成长方形。编辑顶点可以直接修改形状的点、线段和路径，因此可以改变形状本身。

它可以做到：

- 删除顶点
- 移动顶点
- 调整曲线控制柄
- 将曲线改成直线
- 将直线改成曲线
- 打开路径
- 关闭路径

掌握编辑顶点后，PPT 就不只是排版工具，也可以作为轻量级矢量绘图工具使用。

### 5.2 如何进入编辑顶点

操作步骤：

1. 插入一个形状
2. 选中形状
3. 右键点击形状
4. 选择“编辑顶点”
5. 形状边缘出现黑色顶点和路径线时，说明已经进入编辑顶点模式

如果“编辑顶点”是灰色的，可能和 Office 版本、安装状态或对象类型有关。建议使用 Office 2013 及以上版本。

### 5.3 用编辑顶点改变形状

例如把圆形调整成三角形：

1. 插入一个圆形
2. 右键选择“编辑顶点”
3. 删除其中一个顶点
4. 拖动剩余顶点，调整三角形轮廓
5. 如果边仍然是弧线，将线段改成直线段
6. 调整三个点的位置，得到新的三角形

这个案例说明：形状的外观并不是固定的。只要能控制顶点和线段，默认形状就可以被改造成新的轮廓。

### 5.4 顶点类型

编辑顶点时，顶点通常会出现两个控制柄。顶点类型的区别，主要看控制柄的方向和长度。

常见顶点类型包括：

- 平滑顶点
- 直线点
- 角部顶点

#### 5.4.1 平滑顶点

平滑顶点的两个控制柄在同一直线上，并且长度一致。

特点：

- 曲线最平滑
- 两侧弧度比较均匀
- 适合做柔和过渡

#### 5.4.2 直线点

直线点的两个控制柄在同一直线上，但长度可以不同。

特点：

- 两侧仍然保持顺滑
- 两边曲率可以不同
- 适合做不完全对称的曲线

#### 5.4.3 角部顶点

角部顶点的两个控制柄方向和长度都可以不同。

特点：

- 可以形成尖角
- 可以形成明显转折
- 适合做复杂轮廓

### 5.5 线段功能

除了顶点本身，线段也可以编辑。

常见功能：

- 直线段
- 曲线段
- 开放路径
- 关闭路径

直线段可以把曲线变成直线。曲线段可以把直线变成曲线。开放路径可以把闭合形状打开一个缺口，关闭路径可以重新闭合缺口。

如果想观察路径是否打开，可以将形状设置为无填充，只保留线条。

### 5.6 实战案例：绘制裤子轮廓

课程中用裤子作为案例，演示编辑顶点和合并形状的组合用法。

基础轮廓步骤：

1. 插入一个矩形
2. 设置半透明填充，方便观察轮廓
3. 进入“编辑顶点”
4. 调整上方两个顶点，让裤腰略微收窄
5. 调整下方两个顶点，让裤脚向内收
6. 拖动控制柄，让裤子两侧出现弧度

中间镂空步骤：

1. 插入三角形
2. 放在裤子中间需要挖空的位置
3. 使用编辑顶点调整三角形边缘
4. 选中裤子外轮廓和三角形
5. 使用“合并形状 -> 剪除”

细节制作步骤：

1. 使用矩形或其他形状绘制裤缝、口袋等结构
2. 用拆分或剪除得到局部区域
3. 给不同区域设置不同颜色
4. 做好一侧后复制并水平翻转
5. 去掉多余轮廓线，微调细节

这个案例的重点不是裤子本身，而是理解复杂插画可以拆成基础形状、顶点调整和布尔运算。

### 5.7 编辑顶点的价值

编辑顶点和合并形状配合后，可以制作很多原本需要外部素材的视觉元素。

例如：

- 图标
- 插画人物
- 动物插画
- 手表等物品造型
- 商业插画
- 复杂装饰图形

课程中提到的小狐狸、卡西欧手表、赛博朋克插画、商业插画等案例，本质上都可以通过形状、编辑顶点和合并形状完成。

### 5.8 本节总结

本节重点是理解编辑顶点。

核心知识：

- 编辑顶点可以改变单个形状的内部结构
- 顶点编辑要看控制柄的方向和长度
- 平滑顶点适合柔和过渡
- 直线点适合顺滑但不完全对称的曲线
- 角部顶点适合尖角和复杂轮廓
- 线段可以在直线段、曲线段、开放路径和关闭路径之间切换
- 编辑顶点和合并形状结合后，可以大幅提升 PPT 绘图能力

一句话记忆：

```text
合并形状负责组合，编辑顶点负责变形
```

## 6. 如何用 PPT 制作一个酷炫的“流星”动画

这一节用 PPT 制作一个由星空、极光、流星、小飞机和喷气效果组成的动态场景。核心不是依赖复杂素材，而是把渐变、透明度、图层、组合和动画窗格叠加起来。

### 6.1 整体设计思路

这个动画主要由四部分组成：

- 星空背景
- 星星效果
- 极光效果
- 流星和小飞机

整体思路是：

1. 用射线渐变做出深蓝色宇宙背景
2. 用大量小圆点模拟星星
3. 用线性渐变矩形制作极光
4. 用渐变线制作流星
5. 用基础形状和编辑顶点制作小飞机
6. 用动作路径、淡入淡出、重复和延迟完成动画

### 6.2 制作星空背景

先插入一个比页面更大的矩形，方便后续做背景移动动画。

操作步骤：

1. 插入大矩形
2. 打开“设置形状格式”
3. 选择“渐变填充”
4. 将渐变类型设置为“射线”
5. 设置多个渐变光圈
6. 颜色以深蓝、亮蓝、接近黑色的深蓝为主
7. 调整射线方向和亮暗区域

注意事项：

- 亮蓝色不要太多
- 外圈需要接近黑色或深蓝色
- 渐变光圈需要反复微调
- 背景要大于页面，避免移动时露出边缘

为了避免误选背景，可以将背景复制后设置为页面背景。

### 6.3 制作星星效果

星星本质上是大量白色小圆点。

操作步骤：

1. 插入椭圆
2. 设置白色填充、无边框
3. 按住 `Ctrl` 拖拽复制多个小圆点
4. 组合一批星星
5. 复制星星组
6. 旋转、移动、缩放到不同位置
7. 设置不同透明度

透明度可以分批调整：

- 一批较亮
- 一批约 `30%` 透明度
- 一批约 `50%` 透明度
- 一批约 `69%` 透明度

目标是让星星有远近层次，不要像均匀铺开的白点。

### 6.4 制作极光效果

极光可以用矩形加线性渐变制作。

操作步骤：

1. 插入大矩形
2. 设置为渐变填充
3. 渐变类型选择“线性”
4. 使用蓝绿色作为主色
5. 两端设置较高透明度
6. 中间保留较明显的蓝绿色
7. 适当旋转和缩放

注意事项：

- 绿色不要太鲜艳
- 两端要逐渐透明
- 可以复制多层极光，改变角度和位置

### 6.5 绘制流星

流星可以用渐变直线制作。

操作步骤：

1. 插入一条斜线
2. 设置为渐变线
3. 两端颜色都设为白色
4. 尾部透明度设高
5. 头部保持较明显
6. 线条宽度调细
7. 复制多条不同长度的流星

流星不要太粗，否则会像普通线条。多条流星的位置、长度和动画延迟都要不同。

### 6.6 绘制小飞机和喷气效果

飞机可以用简单形状拼出来。

飞机主体：

1. 用细长矩形制作机身
2. 用编辑顶点调整机头
3. 用三角形制作机翼和尾翼
4. 设置白色填充、无边框
5. 组合成飞机

喷气尾迹：

1. 插入等腰梯形
2. 放在飞机尾部
3. 使用编辑顶点调整形状
4. 设置渐变填充
5. 靠近飞机的位置较明显，尾部逐渐透明

突破大气层效果：

1. 插入不完整圆或弧形
2. 设置白色填充、无边框
3. 使用编辑顶点保留必要弧形
4. 设置渐变填充
5. 复制更大的弧形叠加

飞机、喷气尾迹和大气层效果需要组合后再设置动画。

### 6.7 设置动画

#### 6.7.1 背景移动

背景使用动作路径制造镜头游走感。

设置建议：

- 动作路径选择直线
- 持续时间约 `5 秒`
- 设置自动翻转
- 重复到幻灯片末尾

#### 6.7.2 星星闪烁

星星使用淡入动画模拟闪烁。

设置建议：

- 不同星星使用不同持续时间
- 不同星星设置不同延迟
- 重复到幻灯片末尾
- 不要让所有星星同时闪

#### 6.7.3 极光淡入

极光可以设置淡入或淡出类动画。

设置建议：

- 持续时间约 `2 秒`
- 从上一项开始
- 多层极光可设置不同延迟

#### 6.7.4 流星飞过

流星使用直线动作路径。

设置建议：

- 路径方向和流星线条方向一致
- 从页面右上方飞向左下方
- 多条流星设置不同持续时间
- 多条流星设置不同延迟
- 重复到幻灯片末尾

#### 6.7.5 小飞机进入

飞机组合可以使用飞入动画。

设置建议：

- 设置平滑结束
- 适当延迟出现
- 喷气和大气层效果配合飞机出现
- 播放时反复预览节奏

### 6.8 本节总结

这一课的重点是用 PPT 做出带氛围感的动态场景。

关键经验：

- 渐变决定画面质感
- 透明度决定空间层次
- 动画延迟决定自然程度
- 图层关系决定画面是否清楚
- 背景、星星、极光、流星和飞机要分别处理

一句话总结：

```text
高级感来自细节叠加，而不是单个复杂操作
```

## 7. 不用 C4D，酷炫的三维地球动画，用 PPT 也能完成

这一节讲的是三维星球和地球动画。课程主线分为三部分：先用 Paint 3D 快速制作三维模型，再用 PPT 的三维模型动画和平滑切换做效果，最后补充 C4D 和 Excel Power Map 的扩展玩法。

### 7.1 用 Paint 3D 制作三维元素

Paint 3D 的优势不是专业建模，而是能快速做出可插入 PPT 的三维元素。

常用功能：

- `3D 形状`
- 贴纸
- 3D 文本
- 神奇选择

基础操作：

1. 打开 Paint 3D
2. 新建项目
3. 插入球体、立方体等基础模型
4. 调整模型角度
5. 用贴纸给模型添加纹理
6. 关闭显示画布，让画面更干净

神奇选择类似抠图功能，可以从图片中提取主体，再生成贴纸。

### 7.2 制作三维文字

三维文字可以直接在 Paint 3D 中制作。

操作步骤：

1. 点击“文本”
2. 选择“3D 文本”
3. 输入文字
4. 设置颜色
5. 旋转文字角度
6. 调整文字厚度和宽度
7. 导出为 `3MF` 文件
8. 插入 PPT

三维文字生成后，可编辑性有限，适合用于特效展示，不适合作为大量正文内容。

### 7.3 制作三维星球

星球可以用球体加贴纸制作。

操作步骤：

1. 在 Paint 3D 中插入球体
2. 按住 `Shift` 保持比例
3. 添加星球或火星类图片贴纸
4. 调整贴纸大小、位置和角度
5. 多贴几张，覆盖明显缝隙
6. 调整到远看比较完整
7. 导出模型

注意事项：

- 贴纸边缘不要太硬
- 纹理不一定要完全真实
- 重点是远看形成三维球体质感

### 7.4 将模型插入 PPT

常见方式有两种。

第一种是直接复制粘贴：

```text
Paint 3D -> Ctrl + C -> PPT -> Ctrl + V
```

缺点是 PPT 中可能出现不自然的默认光源。

第二种是导出为三维模型：

1. Paint 3D 中点击“菜单”
2. 选择“另存为”
3. 选择“三维模型”
4. 格式选择 `3MF`
5. 保存后插入 PPT

推荐使用 `3MF`，通常颜色更稳定，也更少出现奇怪光源。

### 7.5 用 PPT 制作三维动画

PPT 对三维模型提供了专用动画，也可以使用平滑切换做页面之间的三维过渡。

平滑切换流程：

1. 在第一页放置三维模型
2. 复制这一页
3. 在第二页改变模型的位置、大小和角度
4. 给第二页设置“切换 -> 平滑”
5. 播放时，模型会自动在两页之间旋转过渡

三维星球和三维字母展开效果，本质就是复制页面后改变角度，再用平滑切换自动补间。

### 7.6 用 C4D 制作更精细的地球

如果需要更精细的地球模型，可以用 C4D 制作。

准备素材：

- 彩色地球贴图
- 黑白地形图
- 凹凸或置换纹理图

基础做法：

1. 打开 C4D
2. 插入球体
3. 新建材质
4. 去掉反射
5. 在颜色通道加载地球纹理
6. 将材质拖到球体上
7. 导出为 `FBX`
8. 导出时勾选嵌入纹理
9. 在 PPT 中插入 `FBX`

注意事项：

- 不推荐导出为 `OBJ` 或 `3DS`
- 推荐使用 `FBX`
- 贴图越高清，模型越清晰，但 PPT 加载也可能更慢
- 球体分段太少会显得不够圆滑

### 7.7 用置换和凹凸增强地球细节

置换可以让地球表面产生起伏。

原理：

- 白色区域凸起
- 深色区域降低或保持平面
- 黑白图的明暗会变成模型表面的高低变化

操作思路：

1. 给球体添加置换效果
2. 在置换着色器中加载黑白地形图
3. 提高球体分段
4. 调整置换高度和强度
5. 在材质中添加凹凸纹理
6. 转换为可编辑模型
7. 导出为 `FBX`

分段越高，细节越丰富，但软件会越卡。课程中提到可以在精度和性能之间做平衡。

### 7.8 在 PPT 中使用三维地球

将 `FBX` 地球插入 PPT 后，可以继续添加三维动画。

常用效果：

- 转盘
- 三维旋转
- 平滑切换
- 自定义旋转角度

例如可以设置 `3600°` 旋转，让地球多圈自转。时长需要根据页面节奏调整，太快会显得混乱，太慢会拖节奏。

### 7.9 Excel Power Map 三维地图

课程最后补充了 Excel 的三维地图功能，也叫 Power Map。

适合的数据类型：

- 有国家、城市、地区等地理维度
- 有年份等时间维度
- 有排放量、销量、人口等数值维度

操作步骤：

1. 打开 Excel 数据表
2. `Ctrl + A` 选中数据
3. 点击“插入”
4. 选择“三维地图”
5. 点击“新建演示”
6. 设置高度、类别和时间字段
7. 播放时间轴，查看数据变化

还可以：

- 切换地图主题
- 调整柱形高度和厚度
- 添加热力图图层
- 新建多个场景
- 设置场景转场
- 导出视频

### 7.10 本节总结

本节课的核心是理解三维素材进入 PPT 后的几种玩法。

重点包括：

- Paint 3D 适合快速制作简单三维模型、贴纸星球和三维文字
- `3MF` 是 Paint 3D 模型插入 PPT 的推荐格式
- PPT 的三维模型动画和平滑切换适合做星球转场
- C4D 可以制作更精细的地球模型
- Excel Power Map 适合做地理数据和时间序列数据可视化

学会地球后，同样方法也可以扩展到月球、太阳或其他星球。

## 8. PPT“催眠术”：如何设计一个动态的迷幻图谱

这一节讲的是用 PPT 制作动态迷幻图谱。核心思路并不复杂：先设计一个基础图形元素，再用 iSlide 的环形布局大量复制、旋转和排列，最后配合 PPT 动画，让静态图形产生旋转、扩散和催眠般的视觉效果。

### 8.1 迷幻图谱的设计逻辑

迷幻图谱本质是：

```text
基础元素 -> 环形排列 -> 动画
```

常见基础元素包括：

- 圆形
- 圆弧
- 三角形
- 圆角六边形
- 正方形
- 多边形
- 曲线或线段

关键在于先找到简单元素，然后通过重复排列形成复杂图案。不同形状、颜色、渐变方向和透明区域都会带来不同效果。

### 8.2 准备工具

本节主要使用：

- PowerPoint
- iSlide 插件

主要用到 iSlide 中的：

- 设计排版
- 环形布局

如果没有 iSlide，也可以手动复制和旋转，但效率会低很多。

### 8.3 制作基础圆形元素

先设置黑色背景，让高饱和渐变线条更明显。

操作步骤：

1. 右键幻灯片背景
2. 选择“设置背景格式”
3. 将背景设置为黑色
4. 插入圆形
5. 设置填充为无填充
6. 设置线条粗细
7. 右键打开“设置形状格式”
8. 将线条设置为渐变线
9. 将渐变角度设置为 `90°`
10. 两端设置不同颜色
11. 中间渐变光圈设置为 `100%` 透明度

这样圆形中间会出现断裂，只保留两段彩色弧形。

### 8.4 使用 iSlide 环形布局

选中基础圆形后，进入：

```text
iSlide -> 设计排版 -> 环形布局
```

环形布局会将当前图形复制成多个对象，并围绕中心排列。

常见参数：

- 数量
- 起始角度
- 偏移角度
- 允许重叠
- 布局半径
- 布局方向
- 旋转方式

参数理解：

- 数量越多，图案越密集
- 布局半径越小，图案越集中
- 布局半径越大，图案越扩散
- 自动旋转会让每个元素随环形路径自然旋转
- 允许重叠通常建议勾选，方便固定首尾位置

示例参数：

- 数量：`30`
- 布局半径：约 `22.8`
- 旋转方式：自动旋转
- 允许重叠：勾选

### 8.5 尝试不同基础元素

迷幻图谱没有固定答案，重点是不断尝试形状和参数。

#### 8.5.1 三角形图谱

操作思路：

1. 插入三角形
2. 设置无填充
3. 设置渐变线条
4. 使用蓝、绿、黄等颜色
5. 适当加粗线条
6. 使用 iSlide 环形布局
7. 数量设置为 `40` 到 `50`
8. 设置自动旋转
9. 调整布局半径和偏移角度

数量不要一次性加太高，否则 PPT 容易卡顿。

#### 8.5.2 曲线图谱

曲线或线段可以制作类似管道、旋涡的效果。

操作步骤：

1. 绘制一条简单曲线
2. 设置为渐变线
3. 调整渐变方向
4. 设置紫色到红色等高饱和颜色
5. 使用 iSlide 环形布局
6. 数量可以逐步提高
7. 对比自动旋转和无旋转的差异

自动旋转通常会形成旋涡感，无旋转可能形成管道感。

### 8.6 添加动态效果

静态图谱本身已经有视觉冲击力，动画会进一步增强“催眠术”效果。

#### 8.6.1 进入动画

可以尝试的进入动画：

- 回旋
- 压缩
- 旋转
- 翻转式由远及近
- 基本缩放
- 螺旋飞入

设置建议：

- 持续时间可以设为 `2 秒` 到 `5 秒`
- 元素数量多时，普通动画也会很复杂
- 不同动画可以多试，不必拘泥于一个效果

#### 8.6.2 强调动画

强调动画可以选择“陀螺旋”。

操作步骤：

1. 全选图形
2. 添加动画
3. 选择“更多强调效果”
4. 选择“陀螺旋”
5. 设置持续时间
6. 打开动画窗格
7. 设置平滑开始和平滑结束
8. 设置重复到幻灯片末尾

这样图形会持续旋转，形成明显的迷幻效果。

### 8.7 注意事项

- 基础元素越简单，越容易控制最终效果
- 黑色背景更适合突出高饱和渐变线条
- 渐变线中间可以设置 `100%` 透明度
- 数量越多，视觉越复杂，也越容易卡顿
- 不要一次性把数量加太高
- 自动旋转通常能让图案更自然
- 允许重叠一般建议勾选
- 动画不必复杂，元素多时普通动画也会很有冲击力

### 8.8 本节总结

本节核心是利用 iSlide 的环形布局快速生成复杂图谱。

制作流程：

1. 设置黑色背景
2. 插入基础形状
3. 设置无填充和渐变线条
4. 利用透明渐变制造断裂或镂空效果
5. 用 iSlide 环形布局批量复制并排列
6. 调整数量、起始角度、偏移角度、布局半径和旋转方式
7. 删除不需要的中心基础元素
8. 添加 PPT 动画

这类效果的重点不是固定参数，而是通过形状、颜色、渐变、数量、半径和动画不断试验。掌握“基础元素 + 环形布局 + 动画”这条主线，就可以快速做出动态、酷炫、带有催眠感的迷幻电子图谱。

## 9. PPT 图片墙的 N 种打开方式，秒做高大上 PPT 封面

图片墙是一种把大量图片作为页面主体背景的设计方法，适合快速制作 PPT 封面、过渡页或视觉背景。它的核心价值不是“把图片排满”，而是把图片墙当成一个可复用的封面模板：只要替换图片、Logo 和标题文字，就能快速适配不同学校、企业、行业和汇报场景。

### 9.1 图片墙为什么适合做封面

图片墙最大的好处是降低素材压力。很多时候，很难找到一张足够高清、足够贴合主题的主视觉图片，但中等质量、数量较多的相关图片更容易获取。把多张图片组合成图片墙后，整体视觉会更丰富，也更容易形成氛围感。

常见适用场景：

- 学校类封面：替换为校园建筑、校徽、活动照片等素材
- 商务汇报封面：替换为 CBD、办公场景、企业环境、产品照片等素材
- 医疗或科技主题：可使用 DNA、医疗设备、医生形象、科技感图片，不建议使用血腥或不适合展示的素材
- 企业内部汇报：可使用领导照片、办公场景、产品宣传图、活动照片等

设计原则是：版式框架可以复用，但图片内容、Logo 和标题必须与主题一致。

### 9.2 方法一：用形状做图片填充

不要直接把图片一张张拖到页面上再裁剪、缩放、对齐。这样虽然能做，但效率很低，而且每张图都要反复调整尺寸和比例。

更高效的做法是先用形状搭好图片墙结构，再把图片填充进形状。

操作步骤：

1. 在 PPT 中先绘制多个矩形或长方形，按照想要的图片墙结构排布。
2. 可以用 `Ctrl` 拖拽复制形状，快速生成多个矩形。
3. 根据版面需要调整形状比例，例如第一行放一张大图，第二行放两张图，第三行放三张图。
4. 将所有形状排列整齐后，右键组合。
5. 把组合后的形状整体拖拽到幻灯片背景区域，让它铺满目标版面。
6. 插入需要使用的图片。
7. 选中一张图片，调整到接近目标形状的大小，但图片面积必须略大于目标形状。
8. 复制或剪切图片。
9. 选中目标矩形，打开“设置形状格式”。
10. 选择“填充” -> “图片或纹理填充” -> “剪贴板”。
11. 勾选“将图片平铺为纹理”，并设置为居中对齐。
12. 对其他矩形重复以上操作，依次填充图片。

注意事项：

- 图片必须比目标形状略大，不能小于目标形状，否则填充后容易露出空白或比例异常
- 图片和目标形状的面积越接近，填充效果越稳定
- 填充完成后，可以全选所有形状，统一设置黑色边框
- 边框建议设置为 `3 磅` 到 `4 磅`，会让图片墙更有电影胶片般的质感

### 9.3 增加文字可读性：添加半透明渐变蒙版

图片墙背景通常信息量很大，如果直接叠加文字，标题容易看不清。因此需要给文字区域增加一层半透明黑色渐变蒙版。

操作步骤：

1. 绘制一个矩形，面积要大于图片墙背景。
2. 打开“设置形状格式”。
3. 选择“渐变填充”。
4. 渐变类型选择“线性”。
5. 角度设置为从上到下，例如 `90°`。
6. 设置多个渐变光圈，并统一使用黑色。
7. 顶部光圈透明度可设置较高，例如约 `89%`。
8. 中间光圈透明度可设置为约 `70%`。
9. 底部光圈透明度可设置为约 `30%`。
10. 将形状轮廓设置为“无轮廓”。
11. 把标题文字放在蒙版上方。

这样可以让图片墙保持视觉丰富度，同时保证文字清晰可读。

### 9.4 方法二：用 SmartArt 快速生成形状结构

如果手动画矩形仍然觉得慢，可以利用 SmartArt 先生成一组类似图片墙的图形结构，再转换为普通形状进行图片填充。

操作步骤：

1. 点击“插入”选项卡。
2. 在插图功能组中选择 `SmartArt`。
3. 选择一个接近图片墙排布的 SmartArt 图形。
4. 插入后，点击 SmartArt 的“设计”选项卡。
5. 点击右上角的“转换”。
6. 选择“转换为形状”。
7. 必要时取消组合，手动补充或复制部分形状，让版面更丰满。
8. 全选形状后按 `Ctrl + G` 重新组合。
9. 将组合后的图形铺满目标区域。
10. 再取消组合，按照方法一逐个进行图片填充。
11. 填充完成后统一设置黑色边框。
12. 如果背景白色区域过多，可以把页面背景设置为黑色。
13. 最后复制半透明渐变蒙版，用来承载标题文字。

这个方法的优势是能快速生成较整齐的矩阵结构，减少手动画形状的时间。

### 9.5 方法三：用 PowerPoint 设计灵感一键生成

Office 2016 之后的 PowerPoint 自带“设计灵感”功能，可以根据插入的图片自动推荐排版方案，其中就包含图片墙式版面。

操作步骤：

1. 先插入目标图片。
2. 图片数量不要太多，建议控制在 `5 张左右`。
3. 点击“开始”选项卡中的“设计灵感”。
4. 右侧会出现设计灵感窗格。
5. 等待 PowerPoint 自动分析图片并生成版式。
6. 从推荐方案中选择一张图片墙版式。
7. 根据需要设置背景格式，例如改为黑色。
8. 添加标题文字和必要的蒙版。

优点：

- 速度最快
- 不需要手动排版
- 适合快速出初稿或临时做封面

缺点：

- 插入图片太多时，生成速度会变慢，甚至无法生成
- 自动排版不可控，不能精确指定哪张图大、哪张图小、哪张图在左或在右
- 推荐结果质量不稳定，需要人工筛选

这个方法适合时间紧、图片数量少、对精细控制要求不高的封面制作。

### 9.6 方法四：使用拼图插件或外部工具

如果需要处理大量图片，可以使用类似 `CollageIt Pro` 这样的照片拼贴工具或插件，先在外部生成一张完整图片墙，再导入 PPT。

操作步骤：

1. 打开拼图工具。
2. 选择一个照片拼贴模板。
3. 一次性添加多张图片，例如 10 张或更多。
4. 设置页面方向，例如从 A4 纵向改为横向。
5. 调整边距，让图片之间的间隔更紧凑。
6. 将相框或边框颜色设置为黑色，增强质感。
7. 调整疏密度，根据需要设置图片数量，例如 20、50 或 100 张。
8. 设置导出质量，例如 `100`。
9. 导出为图片文件。
10. 将导出的图片直接拖入 PPT。
11. 调整图片大小，让它铺满幻灯片背景。
12. 再添加标题文字和半透明蒙版。

这个方法适合图片数量较多的场景。它的优势是拼贴效率高、图片数量可控，缺点是生成后整体是一张图片，后续在 PPT 中不方便单独调整某一张小图。

### 9.7 四种方法对比

| 方法 | 适合场景 | 优点 | 局限 |
| --- | --- | --- | --- |
| 形状图片填充法 | 想要精细控制版式 | 可控性强，质感好 | 操作步骤较多 |
| SmartArt 转形状 | 想快速生成规整结构 | 比手动画形状更快 | 仍需逐个填充图片 |
| 设计灵感 | 快速生成初稿 | 速度最快，几乎一键完成 | 图片数量不宜太多，版式不可控 |
| 拼图插件或外部工具 | 大量图片拼贴 | 适合几十张甚至上百张图片 | 导入 PPT 后不便单独编辑小图 |

### 9.8 本节总结

图片墙是一种高复用度的 PPT 封面套路。它不依赖单张高质量大图，而是通过多张相关图片共同营造氛围。制作时先确定版式框架，再根据主题替换图片、Logo 和文字，就能快速生成适配学校、企业、医疗、科技、商务汇报等不同场景的封面。

实际制作时，推荐优先掌握“形状图片填充法”，因为它可控性最好；需要快速搭结构时可以使用 SmartArt；需要快速出方案时可以尝试设计灵感；图片数量很多时，可以借助拼图工具先生成图片墙，再导入 PPT。

## 10. 快乐地“喝醉”，一起来做一个 PPT 酒杯动画

### 10.1 动画效果与核心原理

本节制作的是一个“红酒倒入酒杯”的 PPT 动画：播放时，酒杯内部的红色液面带着波浪从下方向上升起，最终停在杯口附近，看起来像酒被慢慢倒满。

这个效果的本质不是复杂的液体模拟，而是一个遮罩动画：

- 真正运动的是一个放在后方的红色波浪矩形
- 前方用一个“中间被掏空的酒杯形状”作为遮罩
- 播放时，观众只能看到酒杯内部的局部区域，因此会误以为红酒正在杯子里上涨
- 波浪矩形从右下角向左上角移动，停下时刚好填满杯身，就形成“倒满”的视觉效果

关键点是：动画对象很简单，复杂感来自遮罩造成的局部可见。

### 10.2 绘制红酒杯轮廓

先准备一张红酒杯参考图，可以从网上搜索红酒杯图片，放到 PPT 中作为描摹参考。

操作步骤：

1. 点击“插入” -> “形状”。
2. 在线条类形状中选择“自由形状”。
3. 沿着参考图的酒杯轮廓依次描点，先画出大致外形。
4. 右键形状，选择“编辑顶点”。
5. 通过拖动顶点两侧的白色控制柄，调整杯身弧度。
6. 根据需要把部分顶点设置为“直线点”或“平滑点”，让杯身、杯脚和底座更自然。

为了方便描摹，可以先把绘制出来的形状设置为半透明填充，例如 50% 透明度，这样能同时看到参考图和自己画的轮廓。

绘制时不必一开始就追求完美，先用少量点把轮廓搭出来，再进入编辑顶点逐步修正。杯口、杯身弧线、杯脚连接处是最需要调整的地方。

### 10.3 绘制波浪矩形

波浪矩形是红酒液面的主体。它由上方波浪线和下方矩形区域组成，最终会放在遮罩后面运动。

有两种做法。

第一种是在 PPT 中手动画：

1. 插入“任意多边形”或“自由形状”。
2. 画出一条高低起伏的波浪曲线。
3. 右键“编辑顶点”。
4. 将波浪上的顶点设置为“平滑点”。
5. 调整每个顶点的控制柄，让波峰和波谷更自然。
6. 在波浪下方补一个矩形区域。
7. 将波浪和矩形组合，设置为红色或深红色填充，并取消轮廓。

第二种更快：使用在线波浪生成工具，例如 `getwaves.io`。

操作步骤：

1. 打开 `getwaves.io`。
2. 选择波浪样式。
3. 调整波浪起伏程度，不需要太夸张，轻微起伏即可。
4. 如果不满意，可以点击随机生成，直到出现合适的波形。
5. 下载 SVG。
6. 回到 PPT，点击“插入” -> “图片”，插入下载的 SVG。
7. 右键 SVG，选择“转换为形状”。
8. 如果波浪长度不够，可以复制一份，执行“水平翻转”，让头尾相接。
9. 继续复制、翻转、拼接，直到波浪长度足够覆盖整个酒杯动画路径。
10. 在下方添加一个矩形，与波浪组合成完整的波浪矩形。

注意：波浪矩形要比酒杯宽一些，这样移动时不会露出断口。

### 10.4 制作酒杯遮罩

遮罩是本节最重要的结构。它决定了观众只能看到“酒杯内部”的红酒。

制作步骤：

1. 复制一份已经画好的红酒杯。
2. 用一个矩形放在杯身和杯座分界的位置，将酒杯拆成杯身和底座两部分。
3. 框选酒杯和矩形，使用“合并形状” -> “拆分”。
4. 保留上半部分杯身，用它作为酒液显示区域的参考。
5. 再绘制一个大矩形，覆盖整个酒杯区域。
6. 同时选中大矩形和杯身形状。
7. 点击“合并形状” -> “拆分”，让大矩形中间被酒杯形状掏空。
8. 将这个外侧遮罩设置为白色填充、无轮廓。
9. 将幻灯片背景设置为浅灰色或其他背景色。
10. 将酒杯底座放到最上层，并设置成与背景一致的填充色。

这样，中间的酒杯区域被“挖空”，后面的波浪矩形只有经过这个空洞时才会被看见。

### 10.5 添加酒杯轮廓

为了让遮罩不像一个生硬的白色块，还需要单独叠加一层酒杯轮廓。

操作步骤：

1. 复制一份完整的红酒杯形状。
2. 设置为“无填充”。
3. 设置黑色轮廓，线宽可以使用 `1.5 磅` 到 `2.5 磅`。
4. 如果杯口上方有封闭线，可以右键“编辑顶点”。
5. 在杯口位置设置为“开放路径”。
6. 删除或调整杯口顶部多余顶点，让它更像真实酒杯。

层级关系建议如下：

1. 最底层：波浪矩形。
2. 中间层：白色遮罩。
3. 上层：杯座和杯身轮廓。
4. 最上层：需要显示的文字或百分比数字。

### 10.6 设置倒酒动画

将波浪矩形放在酒杯后方偏右下的位置，让它一开始只露出少量或完全不露出。

添加动画：

1. 选中波浪矩形。
2. 点击“动画” -> “添加动画”。
3. 选择“其他动作路径”。
4. 选择类似“对角线”的路径，方向设置为从右下往左上。
5. 拖动路径终点，让波浪矩形最终刚好覆盖酒杯内部。
6. 打开“动画窗格”。
7. 将持续时间设置为 `5 秒`。
8. 打开动画效果选项，把“平滑开始”和“平滑结束”都关闭。

关闭平滑开始和平滑结束的原因是：倒酒上涨应该是相对均匀的，如果动画默认先慢后快或先快后慢，会显得不像液体持续倒入。

### 10.7 设置红酒颜色

红酒不要只用纯红色，最好设置渐变，让它更有质感。

建议设置：

1. 选中波浪矩形。
2. 打开“设置形状格式”。
3. 选择“渐变填充”。
4. 角度设置为 `90°`。
5. 渐变色标都使用红色系。
6. 上方色标可以稍微提高亮度。
7. 下方色标适当降低亮度，让底部更深。
8. 取消轮廓或设置为无轮廓。

这样红酒看起来会更深邃，不会像普通红色块。

### 10.8 添加百分比数字变化

课程中还演示了用数字表现倒酒进度，例如 `0%`、`20%`、`40%`、`60%`、`80%`、`100%`。

动画逻辑是：上一个数字淡出，下一个数字淡入。

操作步骤：

1. 分别创建 `0%`、`20%`、`40%`、`60%`、`80%`、`100%` 六个文本框。
2. 将它们放在同一位置。
3. 设置左右居中、上下居中。
4. `0%` 一开始就显示，只需要添加一个“淡化退出”。
5. `20%` 添加两个动画：“淡化进入”和“淡化退出”。
6. 后面的 `40%`、`60%`、`80%`、`100%` 复制 `20%` 的动画设置。
7. 打开“动画窗格”，按顺序排列，让上一个数字退出后，下一个数字进入。
8. `100%` 是最终状态，不要保留它的退出动画，需要删除 `100%` 的淡化退出。

可以使用“动画刷”快速复制动画。双击动画刷后，可以连续刷到多个数字对象上，最后点击空白处退出动画刷模式。

### 10.9 添加倒酒音效

为了让动画更完整，可以插入倒酒音效。

操作步骤：

1. 准备一个倒红酒或倒水的 MP3 音效。
2. 点击“插入” -> “音频”，插入音效文件。
3. 选中音频图标。
4. 点击“播放” -> “裁剪音频”。
5. 将音频裁剪到与动画接近的长度，例如 `5 秒` 或 `5.3 秒`。
6. 设置“渐弱”，例如 `0.25 秒`，让声音自然结束。
7. 设置音频为“自动开始”。
8. 不要勾选“跨幻灯片播放”。
9. 不要勾选“循环播放”。

需要注意：音频播放本身也属于一种动画。如果插入后发现声音在全部动画结束后才播放，需要调整动画顺序。

修正方法：

1. 打开“动画窗格”。
2. 找到音频播放动画。
3. 将它设置为“从上一项开始”。
4. 把音频播放动画拖到动画窗格最上方。
5. 这样音效就会在倒酒动画开始时同步播放。

### 10.10 本节总结

这个红酒动画的关键不是复杂绘图，而是理解遮罩：

- 酒杯本身负责限制可见区域
- 红色波浪矩形负责运动
- 观众看到的只是波浪矩形经过杯身空洞的局部
- 动作路径从右下到左上，制造液面上升的错觉
- 持续时间约 5 秒，并关闭平滑开始、平滑结束，让倒酒速度更自然
- 数字进度通过淡入淡出逐个切换
- 音效需要裁剪并放到动画窗格最前面，才能和画面同步

## 11. 一节课讲透 PPT 图片，半小时造就“用图高手”

### 11.1 图片在 PPT 中的三种作用

图片不是装饰品，它在 PPT 里主要解决三个问题：

1. 提升设计感。同样的文字、版式和图形，只要换上一张合适的背景图，页面的观感就会明显提升。尤其是封面、章节页、汇报页，图片能快速让页面显得更完整、更专业。
2. 辅助表达。文字需要观众先阅读、再理解、再在脑中形成画面；图片可以直接提供视觉画面，降低理解成本。比如解释“太空”“城市”“科技”等概念时，一张合适的图比一大段文字更直观。
3. 传递情感。图片可以表达文字难以快速传递的情绪。比如“衰败、破灭、凋零”可以用落叶、废墟、暗色场景来表现；“震撼、开阔、积极”可以用星空、地球、城市天际线、海洋等画面来表现。

### 11.2 什么是“高大上”的图片

“高大上”不是具体风格，而是一种让人产生愉悦、开阔、震撼、信任感的视觉氛围。

常见可用方向包括：

- 自然开阔类：天空、海洋、山脉、森林、星空、地球
- 城市建筑类：CBD、城市天际线、高楼、夜景、建筑线条
- 科技未来类：宇宙、地球、光线、线条、数据感、科技感场景
- 壁纸类素材：手机壁纸、电脑系统壁纸、品牌默认壁纸

系统壁纸特别适合作为 PPT 背景，因为它们通常经过筛选，画面质量高，同时不会过度抢夺文字注意力。

### 11.3 搜图网站和工具推荐

课程中推荐了三类资源：

| 工具 | 用途 | 使用建议 |
| --- | --- | --- |
| Bing 图片搜索 | 搜高清图片、透明底图片 | 优先使用国际版；关键词尽量用英文；筛选图片尺寸为 `Large`；需要免抠图素材时选择透明背景类型 |
| Unsplash | 搜高质量无版权摄影图 | 适合找封面、背景、大图、氛围图 |
| PPT 图片插件 | 聚合搜索多个无版权图库 | 适合在 PPT 内直接搜索和插入图片；部分插件支持中文自动翻译搜索 |

使用 Bing 搜图时，注意筛选条件：

- 图片尺寸选大图，避免模糊
- 需要透明素材时，筛选透明背景图片
- 黑白棋盘格背景通常表示图片背景是透明的
- 英文关键词通常比中文关键词更容易搜到高质量结果

### 11.4 搜图的关键不是网站，而是思路

好的素材不只是靠素材库，而是靠搜索前的联想。

不要直接把抽象词丢进搜索引擎，比如：

- `信号强大`
- `勇敢`
- `高端`
- `未来`
- `母校`

这些词太抽象，搜索引擎会给出杂乱、低质、不可控的结果。

更好的方法是先把抽象词变具体：

| 抽象词 | 联想方向 | 可搜索的具体关键词 |
| --- | --- | --- |
| 信号强大 | 什么东西承载信号？ | 手机、路由器、基站、天线、Wi-Fi 设备 |
| 勇敢 | 谁或什么事体现勇敢？ | 登山者、宇航员、攀登珠峰、登月 |
| 高大上 | 什么环境让人舒畅、震撼？ | 星空、海洋、城市夜景、CBD、山脉 |
| 母校 | 谁拍得最好？图片在哪里沉淀？ | 学校摄影协会、公众号、微博、校友摄影作品 |

核心方法：

- 联想人：谁能代表这个概念
- 联想事物：什么物体能承载这个概念
- 联想环境：什么场景能传递这种氛围
- 联想情绪：希望观众产生什么感受
- 联想具体事件：有没有具体行为或故事能表现它

搜索引擎不会替你思考，真正的搜索大部分发生在脑子里。

### 11.5 案例：如何为“母校”找图片

如果直接搜索“深圳大学”，结果可能是老旧、模糊、风格过时的图片。

更好的思路是：

1. 想清楚：谁最可能拍出好看的校园照片？
2. 答案是摄影师，尤其是学校摄影协会、学生摄影社群。
3. 再去找这些群体发布图片的地方，比如微博、公众号、社交媒体。
4. 从这些来源中筛选更现代、更清晰、更有氛围感的照片。

这说明：搜索素材库本身并不决定结果，决定结果的是你的联想路径。

### 11.6 图片排版的万能公式

图片和文字结合时，可以使用：

> 对齐 + 对比 + 版面框架

对齐原则是通过规整摆放建立元素之间的视觉联系。常见方式包括：

- 左对齐
- 右对齐
- 居中对齐
- 顶部对齐
- 底部对齐

越是商业、专业、正式的 PPT，越需要强对齐。文字、Logo、图标、图片区域之间都要有明确的对齐关系。

对比原则是通过大小、颜色、形状、粗细、远近等方式突出重点，降低阅读负担。

注意两点：

- 强调的内容要少
- 强调方式要统一

如果一页里到处都是不同颜色、不同粗细、不同样式，反而没有重点。

### 11.7 常见图文版面框架

图文排版不是随便摆放，而是要有版面框架意识。常见框架包括：

1. 居中式。图片作为背景，文字或图形居中放置。适合封面、章节页、金句页。
2. 切割式或杂志式。用矩形、圆形、平行四边形、菱形、圆角矩形等形状切割图片和文字区域，形成更有设计感的版面。
3. 分割式。将页面一分为二，比如左图右文、右图左文、上图下文、上文下图。适合内容解释、观点呈现、产品介绍。
4. 分栏式或图片墙式。将页面分成三栏、四栏、五栏或更多区域，用于多图展示、案例合集、流程分组、图片墙页面。

### 11.8 从纯文字到图文页的处理流程

面对一大段文字，不要直接塞进 PPT。可以按这个流程处理：

1. 阅读正文，把长文字分成几个段落。
2. 删除无意义的叙述性文字。
3. 提炼每段的核心标题。
4. 对文字进行左对齐或统一对齐。
5. 用加粗、颜色等方式突出少量关键词。
6. 加入图标或图片做可视化辅助。
7. 套入图文版面框架，比如左右分割、上下分割、分栏布局。

这样可以把“像 Word 文档一样的 PPT”转化成真正可读、好看、有重点的演示页面。

### 11.9 本节总结

本节围绕 PPT 图片讲了四件事：

- 图片的作用：提升设计感、辅助表达、传递情感
- 图片的选择：高大上不是字面概念，而是能带来开阔、愉悦、震撼、信任感的氛围
- 图片的搜索：Bing、Unsplash、PPT 插件都能用，但真正重要的是搜索思路
- 图片的排版：用对齐、对比和版面框架，把图片和文字组合成专业页面

记住一句话：

> 思路才是最好的搜索引擎。

## 12. 八个美滋滋的 PPT 图片小技巧，你值得拥有

这一节补充的是图片操作层面的实用技巧。上一节更偏图片选择、图片思维和排版方法，这一节重点解决“怎么更快处理图片”：批量导入、批量导出、抠图、叠图、背景融合、Logo 调色、批量裁剪和批量排版。

### 12.1 批量导入图片：使用“相册”功能

如果需要把大量图片按固定数量插入到 PPT 中，不必一张张手动插入。PPT 自带的“相册”功能可以快速生成图片页。

操作步骤：

1. 进入“插入”选项卡。
2. 在“图像”功能组中找到“相册”。
3. 选择图片来源，一般从本地文件夹选择图片。
4. 根据需要设置是否在图片下方新建文本框、是否让所有图片以黑白方式显示、每张幻灯片放几张图片、相框形状和相册主题。
5. 点击创建，PPT 会自动生成一套相册式幻灯片。

适用场景：

- 批量展示照片、作品集、活动图片
- 每页固定放 1 张、2 张或多张图片
- 快速制作纪念相册、图片展示型 PPT

注意事项：

- “相册”功能更适合快速生成图片页，不适合复杂的精细排版
- 如果需要统一版式，可先用相册生成，再手动微调
- 下方文本框可作为图片注释，但不需要说明时可以关闭

### 12.2 批量导出图片：修改 PPTX 后缀并解压

如果拿到一个 PPT 模板，想把里面的图片素材一次性提取出来，不必逐张右键另存为。PPTX 本质上是一个压缩包，可以通过解压方式找到其中的图片资源。

操作步骤：

1. 找到目标 `.pptx` 文件。
2. 复制一份作为备份。
3. 将文件后缀从 `.pptx` 改为 `.rar` 或 `.zip`。
4. 解压这个压缩包。
5. 打开解压后的文件夹。
6. 进入 `ppt/media` 文件夹。
7. 里面就是该 PPT 中使用到的图片、图标等媒体素材。

适用场景：

- 从优秀 PPT 模板中提取图片素材
- 一次性导出大量图片
- 避免逐张右键保存带来的低效率

注意事项：

- 操作前建议复制一份 PPT，避免误改原文件
- `media` 文件夹中的图片通常是原始素材或较高质量版本
- 即使图片在 PPT 中被裁剪过，文件夹里也可能保留原始图片
- 这种方法只适合提取文件中已有的媒体资源，不能提取被矢量重绘的复杂形状

### 12.3 快速抠图：透明色与删除背景

PPT 中有两个常用的抠图功能：“设置透明色”和“删除背景”。前者适合简单背景，后者适合稍复杂的主体抠图。

操作一：设置透明色

1. 选中图片。
2. 进入“图片格式”。
3. 点击“颜色”。
4. 选择“设置透明色”。
5. 鼠标变成取色工具后，点击需要去掉的背景颜色。

适用场景：

- 图片背景是纯色
- 图标、简单插画、黑白底素材
- 快速去掉单一背景色

注意事项：

- 只能较好处理单一颜色背景
- 如果背景颜色复杂、渐变或边缘不干净，效果会比较粗糙
- 同色区域可能被一起去掉，需要谨慎使用

操作二：删除背景

1. 选中图片。
2. 进入“图片格式”。
3. 点击左侧的“删除背景”。
4. 紫色区域代表将被删除的部分，彩色区域代表保留部分。
5. 如果主体被误删，点击“标记要保留的区域”，在主体上画线修正。
6. 如果背景残留，点击“标记要删除的区域”继续调整。
7. 点击“保留更改”完成抠图。

适用场景：

- 人物、产品、主体物抠图
- 背景相对复杂但主体轮廓清晰
- 不想打开 PS，只需在 PPT 内完成基础抠图

注意事项：

- 删除背景比设置透明色更强，但仍不如专业抠图软件精细
- 修正时重点标记主体边缘、手部、衣服等容易误判区域
- 抠图后可以配合阴影、柔化边缘等效果提升自然度

### 12.4 二次曝光效果：调整图片透明度

二次曝光就是把两张图片叠在一起，让画面产生融合、重影或艺术化的视觉效果。PPT 中可以通过图片透明度实现。

操作步骤：

1. 插入两张图片。
2. 将其中一张置于另一张上方。
3. 选中上层图片。
4. 右键选择“设置图片格式”。
5. 打开“图片”设置。
6. 找到“图片透明度”。
7. 将透明度调整到大约 70% 到 80%。
8. 根据画面效果微调位置、大小和透明度。

适用场景：

- 人像与风景叠加
- 建筑、城市、纹理类图片融合
- 制作更有设计感的封面或过渡页

注意事项：

- Office 2016 较新版本、Office 2019、Microsoft 365 通常有图片透明度选项
- 如果旧版本没有该选项，可以用“形状填充图片”的方式替代

旧版本替代方法：

1. 插入一个与图片等大的矩形。
2. 复制目标图片。
3. 选中矩形，右键进入“设置形状格式”。
4. 选择“填充”。
5. 选择“图片或纹理填充”。
6. 从剪贴板插入刚才复制的图片。
7. 在形状填充里调整透明度。
8. 将该矩形叠放到另一张图片上。

### 12.5 图片融入背景：使用半透明渐变蒙版

当图片上需要放文字时，如果图片太花，文字会看不清。可以加一层半透明渐变蒙版，让图片自然融入背景，同时留出清晰的文字区域。

操作步骤：

1. 将图片放到页面中，必要时先组合或粘贴为图片。
2. 将图片裁剪为页面比例，例如宽屏常用 `16:9`。
3. 绘制一个与页面等大的矩形。
4. 右键进入“设置形状格式”。
5. 选择“渐变填充”。
6. 设置为线性渐变，方向可根据文字位置调整，例如 90 度。
7. 将多个渐变光圈设置为同一种颜色：白色背景时，渐变光圈设为白色；深色背景时，渐变光圈设为黑色。
8. 调整各光圈透明度：靠近文字区域的一端透明度低一些或颜色更实；远离文字区域的一端透明度高一些，让图片逐渐显露。
9. 将文字放在蒙版较实的一侧。

适用场景：

- 图片型封面
- 大图背景加标题
- 企业介绍、产品介绍、人物介绍页面
- 想保留图片氛围，又要保证文字清晰

注意事项：

- 蒙版颜色要和页面背景一致，白底用白色渐变，黑底用黑色渐变
- 不要把整张图压得过灰，否则图片会失去质感
- 重点是让文字区域干净，图片区域仍保留层次
- 渐变方向应服务于文字位置，而不是固定套用

### 12.6 快速调整 Logo 颜色：用亮度变黑或变白

Logo 在不同背景上经常需要换成黑色或白色。PPT 中可以通过图片校正里的亮度快速调整，不一定要打开 PS。

操作步骤：

1. 选中 Logo 图片。
2. 右键选择“设置图片格式”。
3. 打开右侧面板中的“图片”。
4. 找到“图片校正”。
5. 调整亮度：将亮度拖到最低，Logo 变为黑色；将亮度拖到最高，Logo 变为白色。

适用场景：

- 彩色 Logo 放在深色背景上看不清，需要改成白色
- 彩色 Logo 放在浅色背景上不协调，需要改成黑色
- 制作统一风格的品牌页、封面页、页脚标识

注意事项：

- 这种方法更适合单色化处理，目标是快速得到黑色或白色 Logo
- 如果 Logo 本身有复杂渐变或透明阴影，效果可能需要再微调
- 调整前建议保留一份原始 Logo，方便恢复彩色版本

### 12.7 批量裁剪图片：使用 iSlide 的裁剪图片与矩阵裁剪

这一部分使用的是 iSlide 插件。它可以批量把多张图片裁剪成统一尺寸，也可以把一张大图裁剪成九宫格、十二宫格、十六宫格等矩阵效果。

功能一：批量裁剪图片

1. 插入多张图片。
2. 全选这些图片。
3. 进入 `iSlide` 选项卡。
4. 点击“设计排版”。
5. 选择“裁剪图片”。
6. 设置统一的宽度和高度，例如 10 厘米 x 8 厘米。
7. 点击裁剪，图片会批量变成统一尺寸。

适用场景：

- 多张图片尺寸比例不一致
- 需要快速做作品墙、照片墙、案例展示
- 想让图片排版更整齐

注意事项：

- 批量裁剪会改变画面可见区域，重要主体可能被裁掉
- 裁剪前最好确认图片主体位置
- 统一尺寸后再进行排版，效率更高

功能二：矩阵裁剪

1. 插入一张大图。
2. 选中图片。
3. 进入 `iSlide`。
4. 点击“设计排版”。
5. 选择“矩阵裁剪”。
6. 设置横向数量和纵向数量，例如 3 x 3 可裁成九宫格，4 x 4 可裁成十六宫格。
7. 根据需要调整横向间距和纵向间距。
8. 点击应用，图片会被拆分成多个格子。

适用场景：

- 九宫格图片墙
- 海报式切割效果
- 社交媒体风格排版
- 制作更有节奏感的封面或过渡页

注意事项：

- 间距越大，切割感越明显
- 间距太大可能破坏图片完整性
- 适合画面主体居中、构图清晰的大图

### 12.8 批量排版图片：矩阵布局与环形布局

图片数量较多时，手动一个个摆放会很慢。iSlide 的布局功能可以快速完成矩阵排列和环形排列。

功能一：矩阵布局

1. 选中多张图片。
2. 进入 `iSlide`。
3. 点击“设计排版”。
4. 选择“矩阵布局”。
5. 设置排列方向、横向数量和纵向数量。
6. 调整横向间距、纵向间距。
7. 根据需要设置横向偏移、纵向偏移或角度。

适用场景：

- 图片墙
- 案例展示
- 多产品、多人物、多场景并列展示
- 需要整齐网格排版的页面

注意事项：

- 先统一图片尺寸，再做矩阵布局，效果更稳定
- 图片数量和每行数量要匹配，否则末行可能不完整
- 间距要服务于页面风格，商务型页面不宜过散

功能二：环形布局

1. 选中图片或图形元素。
2. 进入 `iSlide`。
3. 点击“设计排版”。
4. 选择“环形布局”。
5. 设置数量、起始角度、旋转角度、布局半径等参数。
6. 根据页面效果调整是否旋转元素、是否允许重叠。

适用场景：

- 环绕式图片展示
- 科技感、动态感页面
- 迷幻、旋转、视觉冲击类效果
- 图标或缩略图围绕中心主体排布

注意事项：

- 环形布局参数较多，重点控制数量、半径和起始角度
- 图片过多时容易拥挤，需要放大半径或减少数量
- 适合装饰性和视觉化页面，不适合严肃信息密集页面

### 12.9 本节总结

本节讲了 8 个 PPT 图片处理技巧：

1. 用“相册”功能批量导入图片。
2. 将 `.pptx` 改为压缩包并解压，从 `ppt/media` 批量导出图片。
3. 用“设置透明色”和“删除背景”在 PPT 中快速抠图。
4. 用图片透明度制作二次曝光效果。
5. 用半透明渐变蒙版让图片融入背景，并提升文字可读性。
6. 用图片校正里的亮度，把 Logo 快速变成黑色或白色。
7. 用 iSlide 的“裁剪图片”和“矩阵裁剪”实现批量裁剪。
8. 用 iSlide 的“矩阵布局”和“环形布局”实现批量排版。

这些技巧适合和上一节的图片选择、图片排版方法一起使用：先选对图，再用这些工具提高处理效率和视觉完成度。

## 13. 史上最强大的 PPT 动画入门教程

### 13.1 PPT 动画的三类结构

本节把 PPT 动画分为三类：

- 元素动画：作用在单页中的具体对象上，例如文字、形状、图片、三维模型等
- 组合动画：让同一个对象在同一段时间里叠加多个不冲突的动画效果
- 切换动画：作用在页面与页面之间，也叫过渡动画

元素动画又可分为三类：

- 进入动画：元素从无到有，例如“飞入”“回旋进入”
- 退出动画：元素从有到无，例如“飞出”“回旋退出”
- 强调动画：元素已经在页面上，不进入也不消失，只改变大小、颜色、位置、旋转等状态

动作路径和三维动画也可以理解为特殊的强调动画。

### 13.2 添加、删除与复制动画

给元素添加动画的基本步骤：

1. 选中页面中的元素。
2. 打开顶部“动画”选项卡。
3. 在动画库中选择进入、强调或退出动画。
4. 如果默认显示的动画不够，可以展开动画库，点击“更多”查看完整列表。

当元素左上角出现动画序号小标时，说明动画已经添加成功。

删除动画的方法：

1. 选中已有动画的元素。
2. 在动画选项卡中选择最左侧的“无”。
3. 该元素上的动画会被清除。

复制动画可使用“动画刷”：

- 单击动画刷：把当前元素的动画复制给一个目标元素
- 双击动画刷：连续给多个元素复制同样的动画，点击空白处退出动画刷状态

### 13.3 动作路径：让元素按指定路线移动

动作路径用于控制元素在页面上的移动轨迹。

操作步骤：

1. 选中元素。
2. 打开“动画”选项卡。
3. 展开动画库，在底部找到“动作路径”。
4. 选择直线、弧线、圆形、转弯或“更多动作路径”。

添加动作路径后会出现两个关键点：

- 绿色点：路径起点
- 红色点：路径终点

注意事项：

- 元素摆放的位置不一定等于路径起点
- 动作路径的起点和终点都可以拖动调整
- 右键路径，选择“编辑顶点”，可以像编辑形状顶点一样调整路径、增加顶点或删除顶点
- 如果内置路径不符合需求，可以改用自定义路径，再通过编辑顶点细调轨迹

### 13.4 三维动画：PPT 中的 3D 元素动效

PPT 支持插入三维模型，并为三维模型提供专属动画。常见三维模型格式包括 FBX、OBJ、3MF、PLY、STL、GLB 等。

基本操作：

1. 插入三维模型，例如眼球、星球等。
2. 选中三维模型。
3. 打开“动画”选项卡。
4. 选择三维专属动画。
5. 在效果选项中调整方向、旋转方式、强度等参数。

三维动画内置数量较少，但可以调节方向和强度。强度越高，播放效果越明显。

三维动画中需要区分两个中心：

- 对象中心：以三维模型自身的中心为参考，方向会跟随模型当前角度变化
- 视图中心：以当前视图的正方向为参考，无论模型怎么旋转，运动方向都相对视图保持一致

### 13.5 动画窗格与播放时序

复杂动画必须使用“动画窗格”管理时序。

打开路径：

1. 打开“动画”选项卡。
2. 点击“动画窗格”。
3. 在右侧面板中查看每个动画的播放条。

播放条可以控制动画时长：

- 向右拉长播放条：动画持续时间变长
- 向左缩短播放条：动画持续时间变短
- 拖动播放条位置：调整动画开始时间

PPT 动画常见开始方式：

- 单击时开始：每点击一次播放一个动画，左侧小标代表点击顺序
- 从上一项开始：与上一动画同时开始，常用于组合动画
- 上一项之后开始：上一动画播放完后自动开始，不能拖到上一动画结束之前
- 延迟开始：在上一动画开始或结束后延迟一段时间再播放

设置方法：

1. 在动画窗格中选中动画播放条。
2. 右键选择开始方式，或在顶部“计时”区域设置。
3. 如需延迟，可直接拖动播放条，也可在“延迟”输入框中填写时间。

如果希望页面一进入就自动播放第一个动画，可把第一个动画设置为“从上一项开始”。当动画序号变为 0 时，表示不需要点击即可自动播放。

### 13.6 重复、自动翻转、平滑与弹跳

在动画窗格中双击某个动画，可以打开更详细的动画设置窗口。

常用计时设置：

- 重复：设置重复次数，例如重复 3 次
- 直到下一次单击：动画一直重复，直到用户再次点击
- 直到幻灯片末尾：只要当前页没有切走，动画就持续重复
- 自动翻转：动画播放完后反向播放，例如从左到右后再回到左侧

这些设置适合制作星星闪烁、流星循环、背景装饰持续运动等效果。

缓动设置：

- 平滑开始：从慢到快，模拟加速
- 平滑结束：从快到慢，模拟减速
- 平滑开始 + 平滑结束：先加速再减速，动作更自然

示例参数：

1. 给元素添加“飞入”。
2. 将持续时间设置为 1 秒或 2 秒。
3. 双击动画，设置平滑开始和平滑结束。
4. 播放时元素不再生硬地突然停下，而是符合自然运动规律。

弹跳设置：

- 弹跳结束会让动画末尾产生回弹
- 弹跳结束和平滑结束不能同时存在，开启弹跳结束时，平滑结束会自动归零
- 弹跳时间越长，回弹越明显，同时真正移动的时间会被压缩

### 13.7 触发器：让动画由指定对象控制

触发器可以跳出默认的线性播放顺序，让某个动画由特定对象触发。

设置步骤：

1. 准备两个对象，例如圆形按钮和矩形内容。
2. 给矩形添加动画。
3. 选中矩形动画。
4. 在“高级动画”中点击“触发”。
5. 选择“通过单击开始”。
6. 指定触发对象，例如圆形。

设置完成后，动画序号会变成闪电标识。播放时点击空白处不会触发动画，必须点击指定对象，动画才会播放。

### 13.8 组合动画：多个动画同时作用于一个元素

组合动画的核心是：同一个元素在同一时间段内同时播放多个不冲突的动画。

关键操作：

1. 先给元素添加第一个动画。
2. 添加第二个及更多动画时，必须点击“高级动画”中的“添加动画”。
3. 不能直接在动画库中再次点击，否则会替换原来的动画。
4. 在动画窗格中把后续动画设置为“从上一项开始”。
5. 调整各动画的持续时间、延迟、平滑开始和平滑结束。

示例：齿轮飞入

1. 给齿轮添加“飞入”，方向设为从左到右。
2. 通过“添加动画”再添加“陀螺旋”或旋转动画。
3. 两个动画持续时间都设为 2 秒。
4. 第二个动画设为“从上一项开始”。
5. 两个动画都设置平滑开始和平滑结束，例如各 1 秒。
6. 效果为齿轮边飞入边旋转，并自然停下。

注意：组合动画不能在行为上冲突。例如同一时间既放大又缩小，或既进入又退出，PPT 会优先表现后添加的动画，导致前面的效果失效。

示例：落叶飘散

1. 选中多片叶子，统一添加“飞入”。
2. 将不同叶子的方向分别设为顶部、左上、右上等。
3. 持续时间可设为 1 秒、1.6 秒、2.3 秒等不同值。
4. 延迟可分别设为 0.3 秒、0.5 秒、1 秒、2 秒等。
5. 再通过“添加动画”加入旋转、平面旋转或自定义路径。
6. 将同一片叶子的多个动画靠在一起，并设置为“从上一项开始”。
7. 旋转角度可设置为 180°、270°、360°、720° 等。
8. 如出现空转，可调整弹跳结束、平滑结束或缩短旋转持续时间。
9. 如果路径太生硬，可右键路径编辑顶点，并把节点设为平滑点。
10. 如需让路径与元素位置脱离，可在效果选项中勾选锁定相关设置。

组合动画的难点不在添加，而在细节：方向、时长、延迟、缓动、路径和旋转幅度都要有差异，效果才会自然。

### 13.9 切换动画：页面之间的过渡

切换动画作用于当前页与上一页之间的过渡。

常见切换效果包括：

- 推入
- 擦除
- 分割
- 翻书
- 开门
- 帘布
- 纸飞机
- 立方体
- 蜂巢
- 玻璃
- 折纸
- 涟漪

基本设置：

1. 选中目标幻灯片。
2. 打开“切换”选项卡。
3. 选择一个切换效果。
4. 在右侧设置“持续时间”。
5. 如需统一全篇，点击“应用到全部”。

普通切换动画可调参数有限，主要是持续时间和少量效果选项。

切换动画中要注意“动态内容”：

- 普通华丽切换通常会让背景和内容一起动
- 动态内容类切换会在背景一致时，只让文字或元素内容变化
- PPT 判断“背景一致”时，更倾向于识别版式或母版中的固定背景，而不是每页单独粘贴的一张图片
- 如果希望动态内容生效，应通过视图或母版设置统一背景，再让页面内容发生变化

### 13.10 平滑切换：让页面元素自然过渡

Office 2016 之后，PPT 增加了非常重要的“平滑”切换。它类似 Keynote 中的“神奇移动”，可以让同一元素在页面之间自然过渡。

基本做法：

1. 新建多页幻灯片。
2. 在第一页放置一个元素，例如蓝色矩形。
3. 复制该元素到第二页，改变位置、大小或颜色。
4. 再复制到第三页，继续改变状态。
5. 给第二页、第三页设置“切换” -> “平滑”。
6. 调整切换持续时间，例如 5 秒。

平滑可以自然过渡：

- 位置
- 大小
- 颜色
- 旋转
- 三维模型角度
- 页面之间的对象状态

注意事项：

- 如果只是复制同一个元素并改变位置、大小、颜色，平滑通常可以识别
- 如果编辑了形状顶点或合并形状，PPT 可能认为前后不是同一个元素，平滑会失败
- 解决方法是：在起始元素阶段就让它成为“被编辑过的元素”

改变图形性质仍使用平滑的方法：

1. 创建起始形状，例如圆形。
2. 再创建一个任意辅助形状，放在旁边，二者不要交集。
3. 先选中圆形，再选中辅助形状。
4. 点击“形状格式” -> “合并形状” -> “拆分”。
5. 删除多余辅助形状。
6. 此时 PPT 会把圆形识别为已编辑形状。
7. 复制到下一页后，再编辑顶点改成三角形等形状。
8. 给下一页设置“平滑”，即可实现形状性质变化的过渡。

平滑与三维模型结合时效果更强。做法是复制同一个三维模型到下一页，改变角度、大小和位置，再设置平滑，模型就会在页面切换中自然旋转和移动。

### 13.11 缩放：用页面缩略图做非线性跳转

“缩放”可以把幻灯片做成类似思维导图的结构，让演示从全局跳到局部，再返回全局。

基本操作：

1. 新建一页作为总览页。
2. 在当前页中，按住其他幻灯片并拖入页面。
3. 被拖入的幻灯片会变成可点击的缩放入口。
4. 播放时点击该入口，即可跳转到对应页面。
5. 播放完后可以返回总览页，或继续按顺序播放。

缩放入口可以自定义外观：

1. 选中缩放对象。
2. 打开缩放相关设置。
3. 点击“更改图像”。
4. 可替换为图片、图标、透明图或自定义按钮。

缩放还可以嵌套使用：把当前页面再次拖入当前页面，可以形成循环嵌套的缩放效果。实际使用时应控制层级，避免演示结构过乱。

### 13.12 本节总结

PPT 动画的核心不是把效果堆满，而是理解对象、时序和运动规律。元素动画解决单页对象的进入、退出和强调；组合动画解决多个效果的同步叠加；切换动画解决页面之间的过渡。复杂动画一定要借助动画窗格，重点控制开始方式、持续时间、延迟、平滑、弹跳、重复和触发器。平滑切换和缩放则适合做更高级的页面级叙事与非线性演示。

## 14. 如何用 PPT 绘制一个 MBE 风格的插画

### 14.1 课程目标

这一节围绕 MBE 风格的可爱图形绘制展开。MBE 风格的核心不是复杂技法，而是用圆润、简洁、有趣的基础形状，配合明快渐变、黑色小表情、高光和阴影，做出类似插画软件中的萌系效果。

课程重点有三类：

- 用 PPT 的“合并形状”做出默认形状库里没有的异形图形
- 理解线性、射线、矩形、路径四种渐变模式，以及渐变方向
- 用圆角矩形、弧形、圆形、编辑顶点和透明度，绘制可爱脸部、装饰符号、圆环、阴影和底座等元素

### 14.2 合并形状：PPT 里的布尔运算

PPT 中的“合并形状”本质上就是布尔运算。它可以把多个基础形状拼合、挖空、拆开或只保留重叠区域，从而得到 PPT 默认形状库里没有的图形。

常用操作：

- 减除：先选主体，再按住 `Shift` 选中要挖掉的形状，进入“形状格式” -> “合并形状” -> “减除”。例如在正方形中间放一个圆，水平、垂直居中后减除，就能得到中间镂空的圆孔
- 联合：把两个或多个形状合并成一个整体。比如圆形和矩形叠放后联合，可以得到一体化的圆润图形
- 组合：会保留两个图形不重叠的部分，并把重叠区域挖空，和“联合”不同
- 拆分：把重叠区和非重叠区全部切开，两个图形可能拆成三个或更多独立部分，适合提取局部轮廓
- 相交：只保留多个形状共同重叠的区域，其余部分删除

注意事项：

- 不同 Office 版本中，“合并形状”可能显示为“布尔运算”或其他名称
- 如果按钮是灰色，通常是版本、安装完整性或对象类型问题，建议使用稳定完整的 Office 版本
- 建议把“合并形状”、置于顶层、组合、排列等高频按钮添加到快速访问工具栏，后续绘制会快很多

### 14.3 用圆形和矩形做异形轮廓

很多看起来复杂的 MBE 图形，其实都是圆形、矩形、圆角矩形通过合并形状得到的。

典型做法：

- 镂空图形：正方形加圆形，圆形居中后执行“减除”，得到中间被挖空的图形
- 圆矩组合图形：圆形和矩形尺寸接近，稍微叠放后执行“联合”，得到圆角感更强的整体轮廓
- 圆形灵魂、矩形外壳的异形：让圆形和矩形局部重叠，执行“拆分”，再删除不需要的碎片，保留四条弧边和四条直边混合的形状

操作时要特别关注边缘是否圆润。若拆分后有多余边线或不顺滑的角，可以右键“编辑顶点”，删除多余顶点，或把顶点调整为平滑点、直线点。

### 14.4 临摹参考图的处理

临摹时，如果把参考图直接放在画布底部，绘制过程中很容易误选它。可以这样处理：

1. 右键参考图，剪切。
2. 打开“设置背景格式”。
3. 选择“图片或纹理填充”。
4. 从剪贴板填入参考图。

这样参考图会成为背景，不容易被选中。也可以把参考图放进母版中，达到类似效果。

### 14.5 可爱脸部和主体轮廓绘制

主体可以从半圆或圆润的大轮廓开始，再叠加“手手”一样的小圆角矩形。

操作思路：

- 用半圆或大圆角轮廓确定主体
- 用圆角矩形绘制伸出的圆润小手，圆角拉到最大
- 拉长圆角矩形，让它与主体连接
- 用大矩形配合“减除”切掉多余部分
- 对不够圆润的边缘，用“编辑顶点”微调，必要时删除多余顶点
- 多个主体碎片处理好后，用“联合”合成一个整体

细节对齐时，可以用方向键微调；需要更细的移动时，可按住 `Alt` 减少网格吸附带来的跳动。

### 14.6 脸部表情、弧线和高光

脸部细节以简单为主：

- 眼睛：用黑色小圆或椭圆，左右位置保持均衡
- 腮红：用粉色小圆，放在脸部两侧
- 嘴巴或弧线：不要手动画自由曲线，优先使用“基本形状”里的弧形
- 弧线样式：线条加粗到合适粗细，例如约 `1.5 磅`；在线条设置中把线端类型改为圆形，使两端变圆润
- 高光：用白色小圆，去掉线条，提高透明度到约 `70%` 到 `80%`，叠在主体上即可

这种图形的可爱感主要来自圆角、圆端、半透明高光和适当留白。

### 14.7 圆角矩形和装饰元素

课程中很多小元素都不建议直接使用 PPT 默认的“加号”或硬边图形，因为默认图形往往太直、太硬，不符合 MBE 风格。

更推荐的做法：

1. 用两个圆角矩形交叉叠放制作加号。
2. 旋转其中一个圆角矩形 `90°`。
3. 水平、垂直居中后执行“联合”。
4. 再添加线性渐变，按实际方向设置为 `0°`、`90°` 或其他角度。

星星可以直接使用“四角星”，填充白色、去掉线条。小圆点、小半圆、小椭圆等装饰则根据参考图取色，必要时加轻微渐变或透明度。

### 14.8 圆环、半圆和阴影

圆环如果直接使用 PPT 自带圆环，缩小后可能出现内外宽度不均的问题。更稳的做法是：

1. 按住 `Shift` 绘制正圆。
2. 调整圆环宽度后，如需固定形状，可用另一个不相交的圆形执行“减除”，去掉可调控制点。
3. 固定后再手动编辑顶点，细调内外边距。
4. 圆环通常适合加 `90°` 线性渐变，并通过取色保证和原图一致。

底部阴影可以用小半圆或扁椭圆制作：

- 填充黑色或深色
- 提高透明度
- 放在主体下方或局部结构底部
- 宽度不要超过主体太多，否则会显得笨重

### 14.9 底座与复杂部件的处理

复杂底座可以拆成几个简单图形：

- 用多个圆角矩形或平行四边形拼出主体结构
- 通过“联合”合成整体
- 再用矩形“减除”切掉底部多余部分
- 填充线性渐变，根据图形倾斜方向调整角度，不一定固定为 `90°`，可以尝试 `60°` 左右
- 小虚影可以用两层半透明矩形或圆角矩形叠加，分别设置不同透明度和亮度

如果某段弧形很难画，不要用自由曲线硬描。优先找 PPT 里的弧形，调整大小、弧度、线宽和圆形线端，能更快得到稳定效果。

### 14.10 本节总结

这节课的核心不是记住某一个图形怎么画，而是建立拆解思路：

- 看到复杂轮廓，先判断它由哪些基础形状组成
- 需要挖空、拼接、切割时，用“合并形状”解决
- 需要圆润感时，优先使用圆形、圆角矩形、圆端线条
- 需要通透感时，用渐变、透明度、高光和阴影
- 需要精修时，用编辑顶点，不要怕反复调整

MBE 风格看起来像插画软件画出来的，但在 PPT 中也可以通过基础形状、布尔运算和渐变逐步搭出来。重点是耐心拆形、对齐、取色和微调。

## 15. 欧美高端画册风 PPT，完全拆解教程

### 15.1 画册风格的核心特征

画册风格 PPT 属于偏平面设计的版式类型，常见于欧美商务模板。它通常用不规则或几何化的图片形状搭配少量文字，形成类似画册、杂志内页的视觉效果。

这类页面的关键不在复杂动画，而在三个方面：

- 图片被裁入特殊形状中，形成规整但有变化的视觉块
- 文字区域简洁，标题、正文、标识之间有清晰对齐关系
- 页面整体依赖排列、间距、边框、色彩和图片风格统一来提升质感

本节主要拆解三页画册风格案例，其中重点完整复刻第一张“三角形拼接图片墙”页面，后两页讲解核心形状和处理思路。

### 15.2 图片填充：比“裁剪为形状”更适合复刻

把图片放进形状里，最直接的方法是“裁剪为形状”，例如把图片裁成三角形、圆形或流程图形状。但这种方法经常需要手动调纵横比和裁剪区域，精度不稳定。

更适合画册风格复刻的方法是“图片或纹理填充”：

1. 插入或准备一张图片。
2. 右键复制图片，或剪切图片。
3. 选中目标形状，右键进入“设置形状格式”。
4. 在“填充”中选择“图片或纹理填充”。
5. 图片来源选择“剪贴板”。
6. 勾选“将图片平铺为纹理”，避免图片被强行拉伸变形。
7. 根据需要设置对齐方式，如左上、右上、居中、靠下等。

这样做的好处是：形状可以继续调整大小，内部图片不会被直接拉伸变形，后期修改更灵活。

### 15.3 图片填充中的比例、对齐和旋转

图片填充时要特别注意比例。图片不能随意横向或纵向拉伸，否则会破坏真实感。勾选“将图片平铺为纹理”后，图片会保持原比例，但需要继续处理三个参数。

图片对齐决定形状中显示图片的哪一部分：

- 左上对齐：形状显示原图左上角区域
- 右上对齐：形状显示原图右上角区域
- 居中对齐：形状显示原图中间区域
- 靠下对齐：适合突出图片下方主体

缩放比例可以通过“刻度 X / 刻度 Y”调整。例如从 100% 调到 70%，可以让图片在形状中显示更多内容。但如果缩得太小，图片面积无法铺满形状，就会出现重复平铺的区域。

避免重复平铺的原则是：用于填充的图片长宽都要略大于目标形状，不要小于目标形状，也不必大得过于夸张。

“与形状一起旋转”也很重要：

- 勾选后，旋转形状时，内部图片也跟着旋转
- 取消勾选后，形状旋转，但内部图片方向保持不变

在三角形拼接页面中，经常需要取消“与形状一起旋转”，否则图片方向会显得混乱。

### 15.4 字体识别与图片素材准备

画册风格页面对字体匹配要求较高。遇到不认识的英文字体，可以使用字体识别网站：

- 求字体网：上传截图后，根据提示输入识别出的字母，查找相似字体
- 识字体网：当求字体结果不准确时，可以作为补充识别工具

截图时应尽量截取清晰、放大的英文字母区域。例如案例中的 `FEATURED PROJECTS` 可截取 `TUR` 等字母组合上传识别。识别结果不一定完全准确，需要结合视觉相似度判断。课中提到标题字体接近 `Roboto Thin / Roboto Th` 一类的细体英文字体；大号字母 `P` 可用思源黑体加粗一类偏商务的字体替代。

图片素材不要优先从百度图片找，因为清晰度和可用范围有限。更推荐：

- Bing 图片：适合搜索高清图片，建议使用英文关键词，并通过筛选器选择“特大尺寸”或“透明底图”
- Pexels：适合下载可商用的高质量无版权图片
- 500px：图片质量高，适合练习临摹，但不建议用于正式商业项目
- 花瓣采集工具：可作为浏览器插件辅助采集网页图片素材

选择图片时，要尽量贴近原案例的风格。第一张三角形拼接页面适合使用色彩较浓、视觉冲击强的风景图；第二类黑白案例则应选择黑白图片，不建议混用彩色风景图。

### 15.5 对齐、分布与参考线

画册风格看起来高级，核心原因之一是对齐关系干净。PPT 中常用的对齐工具包括：

- 左对齐、右对齐、顶端对齐、底端对齐
- 水平居中、垂直居中
- 横向分布、纵向分布

制作矩阵或规则排列时，可以先复制多个形状，再用顶端对齐和横向分布统一间距。多行结构可以先将一行组合，再复制成多行，用对齐和分布快速形成整齐网格。

细微调整时，不要只依赖鼠标拖动。应选中对象边框，让文本框或形状进入实线选中状态，然后用键盘方向键进行微调。

如果页面对齐困难，可以在“视图”中打开网格线、参考线。参考线可以拖动，也可以右键修改颜色或添加更多参考线，用来辅助判断文字、图形和图片块是否对齐。

### 15.6 第一页复刻：三角形拼接图片墙

第一页可以拆成三部分：

- 深色背景
- 中央或右侧的大面积三角形图片拼接
- 左侧的标识、标题和小号说明文字

复刻步骤：

1. 设置背景。右键页面空白处，进入“设置背景格式”，选择纯色填充。用取色器吸取原案例中的深色背景。
2. 绘制左上角线性 logo。不必用复杂的编辑顶点。可以用两个等边三角形设置为无填充、白色细线轮廓，再用与背景同色的小圆形遮挡连接处，制造断开的线条效果。最后将这些元素组合。
3. 搭建三角形基准结构。插入等边三角形，复制后旋转或翻转，先做出三个三角形组成的小单元。用垂直居中、横向分布和键盘微调保证三角形之间贴合整齐。
4. 扩展成图片墙。将小单元组合后复制，必要时垂直翻转或水平移动，拼成类似“太阳伞”形态的三角形阵列。画布外露出的部分不用处理，因为最终 PPT 只显示画布范围内的内容。
5. 制作缝隙。不建议逐个缩小三角形来做间距，难以精准。更快的方法是全选三角形，设置与背景色一致的较粗轮廓线，例如 4 到 5 磅。这样看起来就像图片块之间自然形成了缝隙。
6. 填充图片。将准备好的风景图拖入页面。每张图片的长宽只需略大于目标三角形。右键剪切图片，选中对应三角形，使用“图片或纹理填充”并选择“剪贴板”。勾选“将图片平铺为纹理”，根据画面需要设置居中、靠上、靠下或靠右。若图片方向跟着三角形旋转导致不自然，就取消“与形状一起旋转”。
7. 图片数量不足时，可以复制同一张图片，调整缩放、对齐位置和显示区域，让它呈现不同画面。例如一张突出蓝天，一张突出地面或建筑细节。
8. 添加文字。左侧大写 `P` 可使用偏商务的粗体中文或西文字体，如思源黑体加粗，并适当提高透明度，让它像背景装饰字。标题 `FEATURED PROJECTS` 使用细长英文字体，放在大写 `P` 旁边。右下角的小号说明文字使用白色或浅灰色，字号要小，透明度可略高，避免抢主视觉。

### 15.7 第二页与第三页的复刻思路

第二页整体难度较低，重点是对齐。可以用参考线贴住左侧或底部，辅助判断图片块和文字是否整齐。页面中的特殊图形可以直接从 PPT 的“形状”或“流程图”分类中找到相似形状，调整方向后再进行图片填充。

第三页中有一类类似“胶囊形”的长圆角图形。它可以用两个圆形加一个矩形合并出来，但这种做法在后续拉伸时容易破坏圆角半径。更推荐直接使用“圆角矩形”，拖动黄色控制点，把圆角拉到合适程度。这样横向拉伸时，圆角半径不会被破坏。

如果需要让一张图片同时填充多个分散的形状，可以先把这些形状排列好并组合，再对组合后的对象使用图片填充。排列斜向结构时，可以先复制三个圆角矩形，调整大致位置后，依次使用横向分布和纵向分布，让它们形成稳定的斜线节奏。最后再补上特殊的第四个图形。

填充前要去掉形状边框，设置为无轮廓。图片长宽仍然要大于组合后的整体范围，再用剪贴板图片填充并勾选平铺为纹理。

### 15.8 制作注意事项

- 模仿画册风格时，不要只盯着单个形状，要先拆版式：背景、图片块、文字、标识、间距分别是什么关系
- 图片填充时不要破坏比例。出现重复纹理，通常是因为图片尺寸小于目标形状，或缩放比例设置过小
- 不要过度依赖手动拖动。规则排列一定要使用对齐、分布、组合和参考线
- 边距和缝隙可以用与背景同色的粗轮廓线快速实现，比逐个缩小形状更稳定
- 图片风格要统一。彩色案例就选择色彩浓烈、风格接近的图片；黑白案例就使用黑白图片，不要随意混入彩色图
- 临摹时不必把画布外的图形完整画出。只要画布内显示正确，画布外的多余部分可以忽略

## 16. PPT 渐变入门全指南，用渐变做出酷炫金属字

本节系统讲解 PPT 渐变填充的基础操作与绘图应用。很多复杂的 PPT 图形效果，除了依赖合并形状、编辑顶点，更核心的是对渐变光圈、透明度、渐变类型、角度和形状路径的控制。

### 16.1 渐变填充的入口与光圈

在 PPT 中，完整的渐变设置不建议只通过右键的快速填充完成，而应进入：

```text
右键形状 -> 设置形状格式 -> 填充与线条 -> 填充 -> 渐变填充
```

这里的核心控件是“渐变光圈”。渐变光圈用于控制渐变中每个颜色节点的位置、颜色和透明度。

光圈的基本操作：

- 选中某个光圈后，可以修改它的颜色、位置和透明度
- 点击“添加渐变光圈”可以新增颜色节点
- 点击“删除渐变光圈”可以移除当前节点
- 更快的删除方式是选中光圈后向下拖拽
- 在光圈条空白位置点击，可以快速新增一个光圈

渐变光圈越多，颜色过渡越精细；但光圈过多也会增加调整难度。实际绘图时，应围绕明暗关系和质感需要添加光圈，而不是无目的堆叠。

### 16.2 透明度的作用

每一个渐变光圈都可以单独设置透明度。透明度不是简单地“变淡”，而是在绘图时非常有用：它可以让某些颜色节点逐渐消失，形成类似 Photoshop 蒙版的效果。

常见用途包括：

- 做高光，让白色逐渐透明
- 做阴影，让深色向外逐渐消失
- 做玻璃、晶体、光晕等半透明质感
- 做细节叠加时避免边缘过硬

例如，将某个蓝色光圈设置为 `100%` 透明度后，该位置会变成透明区域；如果配合白色光圈和射线渐变，就能做出柔和的高光。

### 16.3 PPT 的四种渐变类型

PPT 的渐变填充主要有四种类型：

- 线性渐变
- 射线渐变
- 矩形渐变
- 路径渐变

它们都通过光圈控制颜色，但扩散方式不同。

线性渐变是一条方向明确的颜色过渡线，最常用于背景、文字、按钮和金属效果。

射线渐变是从某个中心点向外扩散的渐变，适合做圆形高光、光晕和球体质感。

矩形渐变可以理解为以矩形中心向外扩散的渐变，扩散中心是矩形形态。

路径渐变看起来和矩形渐变相似，但关键区别在于：路径渐变会根据当前形状本身改变中心扩散形态。

### 16.4 线性渐变：方向与角度

线性渐变最重要的是方向和角度。PPT 中的角度本质上控制的是“真实渐变方向”与默认光圈方向之间的夹角。

常用角度可以直接记忆：

- `0°`：从左到右
- `90°`：从上到下
- `180°`：从右到左
- `270°`：从下到上
- `45°`：从左上到右下
- `135°`：从右上到左下

理解这个规律后，就可以在默认方向之外手动输入角度，精准控制渐变走向。做金属字、斜向光影、复杂背景时，角度控制尤其重要。

### 16.5 射线渐变与矩形渐变

射线渐变不需要复杂的角度概念，它主要控制中心点位置。PPT 中常见的射线方向包括中心、左上、右上、左下、右下等位置。

射线渐变适合表现：

- 圆形光源
- 球体高光
- 镜头光晕
- 中心发散的柔光

矩形渐变和射线渐变类似，只是它的中心扩散形态更接近矩形。可以把矩形渐变理解为“中心点是矩形形态的射线渐变”。它同样主要控制中心位置，而不是通过角度控制方向。

### 16.6 路径渐变的关键

路径渐变是本节最重要的知识点之一。它看起来和矩形渐变很像，但真正的价值在于：路径渐变会根据形状本身改变渐变中心的形态。

例如：

- 对正方形使用路径渐变，会呈现接近矩形扩散的效果
- 将形状改成圆形，路径渐变会变成圆形扩散
- 将形状改成三角形，中心扩散也会呈现三角形
- 将形状改成菱形、平行四边形等，渐变中心也会随之变化

矩形渐变的中心形态相对固定；路径渐变则会跟随形状变化。这就是路径渐变的核心用途：用形状本身控制射线扩散的形态。

### 16.7 案例一：绘制晶莹剔透的质感球体

绘制球体时，可以用多层渐变叠加来完成。

第一层是球体本身：

- 插入一个圆形
- 设置为无轮廓
- 使用线性渐变
- 角度可设为 `90°`，形成从上到下的明暗变化
- 光圈颜色可以使用深蓝、浅蓝、更深蓝的组合
- 深色光圈略向下移动，让球体底部更重，上方更亮

第二层是高光：

- 再绘制一个大小接近的圆形，覆盖在球体上方
- 设置为无轮廓
- 使用射线渐变
- 光圈颜色统一为白色
- 外侧光圈设置为 `100%` 透明
- 中间光圈可设置为较高透明度，例如 `50%` 到 `60%` 左右
- 将高光位置调整到左上方或合适的受光方向

第三层是阴影：

- 绘制一个椭圆或圆形，放在球体下方
- 设置为路径渐变
- 中心使用深蓝色或深色
- 外侧光圈逐渐提高透明度，最外侧可设为 `100%` 透明
- 去掉轮廓，并置于底层

这样可以得到一个具有玻璃感、晶体感和空间感的球体。想进一步提升质感，可以继续增加细小光圈，强化明暗层次。

### 16.8 案例二：制作金属字体

金属字体的核心是“明暗交替的线性渐变”。

基本步骤：

1. 插入文本框，输入文字。
2. 使用较粗的字体，并适当放大字号。
3. 进入文本选项，设置文本填充为渐变填充。
4. 选择线性渐变。
5. 角度设为 `90°`。
6. 添加多个光圈，例如 8 到 10 个。
7. 颜色按浅灰、深灰、浅灰、深灰交替排列。

这样可以形成金属表面的反光条纹。

为了增强质感，还可以添加文本轮廓：

- 给文字设置渐变轮廓
- 轮廓宽度可设为约 `1.5pt` 到 `3pt`
- 轮廓渐变方向与文字填充方向相反
- 如果填充角度是 `90°`，轮廓可设为 `270°`
- 轮廓颜色同样使用浅灰、深灰交替

最后可以叠加镜头光晕、闪光素材或柔和阴影，让金属字体更有高光和反射感。

### 16.9 实操注意事项

- 不要只看颜色，要同时看光圈位置、透明度和角度
- 光圈数量不是越多越好，关键是控制明暗节奏
- 透明度常用于高光、阴影和柔边，是做质感的关键
- 线性渐变重点看角度，射线和矩形渐变重点看中心位置
- 路径渐变的价值在于随形状变化，适合做特殊形态的发散效果
- 绘制复杂图形时，可以多层形状叠加：底层负责主体颜色，上层负责高光，下层负责阴影
- 金属质感通常依赖深浅灰的频繁交替，而不是单一的灰色渐变
- 做球体、玻璃、晶体效果时，应配合高光层和阴影层，不能只靠一个渐变完成

### 16.10 本节总结

PPT 渐变不是简单的颜色过渡，而是通过光圈、透明度、角度、类型和形状共同控制的绘图系统。掌握这些基础后，就可以进一步绘制更复杂的渐变图形和质感效果。

## 17. 避开地图素材的坑，你需要这个“标准地图服务系统”

本节围绕“地图素材合规使用”展开：如果 PPT、视频封面或课程作品中需要使用中国地图、世界地图、区域地图等素材，最稳妥的做法是优先使用官方发布的标准地图，避免因地图边界、标注、领土范围不规范而引发版权或合规问题。

### 17.1 官方地图素材来源

推荐使用由自然资源部地图技术审查中心推出的“标准地图服务系统”。

在该系统中可以找到多类规范地图素材，包括：

- 中国地图
- 世界地图
- 各省市地图
- 专题地图，例如长江经济带、粤港澳大湾区等
- 不同样式、比例和规格的标准地图

使用官方来源的好处是地图边界、国界、领土范围和标注更规范，适合用于公开发布的视频、PPT、课程和作品展示。

### 17.2 下载格式的选择

在标准地图服务系统中，地图通常可以下载为 `JPG` 或 `EPS` 等格式。

`JPG` 是常见图片格式，适合直接插入 PPT 使用，但它是位图，后期无法灵活修改地图颜色、线条或局部元素。

`EPS` 是矢量格式，更适合需要二次编辑的场景。它可以保留地图的矢量结构，便于后续调整样式。不过 `EPS` 不能直接拖入 PPT 中编辑，通常需要先用 Adobe Illustrator 打开。

### 17.3 将 EPS 地图用于 PPT 编辑

如果需要在 PPT 中调整地图样式，可以按以下流程操作：

1. 从标准地图服务系统下载 `EPS` 格式地图。
2. 使用 Adobe Illustrator 打开 `EPS` 文件。
3. 在 AI 中选中地图矢量元素并复制。
4. 粘贴到 PPT 中。
5. 在 PPT 中右键点击素材，选择“转换为形状”。
6. 再通过“组合”中的“取消组合”，将地图拆分为一个个可编辑的矢量元素。

完成后，地图就可以在 PPT 中进行局部样式处理。

需要注意：不建议随意修改地图本体，尤其是边界、轮廓、国界、行政区划等核心内容。可以适当删除周围的注解、图例或辅助说明，让页面更简洁，但不要改变地图表达的准确性。

### 17.4 使用自助制图功能

标准地图服务系统中还提供“自助制图”功能，可以快速生成需要的地图样式。

以世界地图为例，可以在左侧调整地图要素样式，在右侧单独修改不同国家或大洲的颜色。如果需要在世界地图中突出中国，可以勾选中国国界并设置中国颜色。这样标注出来的领土范围更可靠，不容易出现范围错误。

自助制图还支持一些基础标记功能，例如：

- 打点
- 画线
- 画圈
- 添加文字

完成后通常可以在页面左下角导出。如果导出失败，且对清晰度要求不高，也可以切换到全屏模式截图，再放入 PPT 中继续设计。

### 17.5 本节总结

地图素材不能只看“好不好看”，更要确认来源是否规范、边界是否准确、是否适合公开发布。尤其是涉及中国地图、世界地图、行政区划、国界标注等内容时，应优先使用官方标准地图。

做 PPT 教程、作品展示、视频封面或公开发布内容时，要加强素材审核，避免使用来源不明、边界错误或未经规范审查的地图素材。对于地图本体，不建议随意改动；如果只是为了版面美观，可以优先调整颜色、注解、图例和外围装饰元素。
