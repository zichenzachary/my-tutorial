## 1. PPT 新手入门

### 1.1 PPT 基础操作：迅速告别 PPT 小白身份

这一节面向 PPT 新手，目标不是讲设计审美，而是补齐最常用的软件操作。掌握这些基础操作后，后面做页面排版、修改模板、处理图形和动画时会省下很多重复劳动。

#### 1.1.1 常用快捷键

PPT 的基础操作里，快捷键最值得先掌握。它们不复杂，但能明显提高制作效率。

**保存与选择**

`Ctrl + S` 是最重要的快捷键，制作过程中要随时保存。PPT 文件一旦因为崩溃、断电或误操作丢失，往往很难恢复到原来的编辑状态。

`Ctrl + A` 是全选，但作用范围取决于当前选中的对象：

- 在当前幻灯片编辑区中使用，会选中这一页上的所有元素
- 在左侧缩略图中选中某一页后使用，会选中所有幻灯片页面

**复制、粘贴和撤销**

常见复制粘贴快捷键包括：

- `Ctrl + C`：复制
- `Ctrl + V`：粘贴
- `Ctrl + D`：一步复制，相当于先复制再粘贴
- `Ctrl + Z`：撤销上一步操作
- `Ctrl + Y`：恢复刚刚撤销的操作

`Ctrl + D` 适合快速复制形状、文本框或图片，比连续按 `Ctrl + C` 和 `Ctrl + V` 更直接。

**缩放画面和调整文字**

`Ctrl + 鼠标滚轮` 可以快速放大或缩小编辑视图。做细节调整时，先把页面放大，再操作对象，会比直接在默认比例下拖动更稳。

调整字号时，除了在字号框中输入数值，也可以使用：

- `Ctrl + [`：缩小文字
- `Ctrl + ]`：放大文字

这两个快捷键适合在排版时微调文字大小。

**平行复制**

在 PPT 中拖动对象时，可以组合使用 `Ctrl` 和 `Shift`：

- 按住 `Ctrl` 拖动：复制对象
- 按住 `Shift` 拖动：限制为水平或垂直方向移动
- 按住 `Ctrl + Shift` 拖动：沿水平或垂直方向复制对象

平行复制适合制作横向排列、纵向排列、流程节点、图标组和重复结构。

**复制格式**

复制格式可以理解为快捷键版的格式刷：

- `Ctrl + Shift + C`：复制格式
- `Ctrl + Shift + V`：粘贴格式

它可以把一个对象的填充色、阴影、字体、对齐方式等格式复制到另一个对象上。多个对象需要保持统一风格时，这个操作很高效。

**重复上一步操作**

`F4` 用于重复上一步操作。比如刚刚完成一次平行复制，再按 `F4`，PPT 会继续重复同样的复制动作。

适合使用 `F4` 的场景包括：

- 连续复制多个相同间距的对象
- 重复设置形状格式
- 重复插入或调整类似元素

`F4` 是键盘顶部功能键中的一个键，不是同时按四个键。

**组合与取消组合**

多个分散元素可以组合成一个整体，方便整体移动、缩放或复制。

- `Ctrl + G`：组合
- `Ctrl + Shift + G`：取消组合

组合适合处理由多个形状、图标、文字框组成的小模块。组合后，它们会像一个整体一样被选中和移动。

**选择性粘贴**

`Ctrl + Alt + V` 可以打开选择性粘贴。普通粘贴会保留对象原本的类型，例如形状仍然是形状，文字仍然是文字；选择性粘贴可以把对象粘贴为图片等其他格式。

常见用途是把复杂对象粘贴成图片，避免对象被继续拆改，也可以减少格式错乱。

#### 1.1.2 快速访问工具栏

快速访问工具栏用于放置常用命令。把高频操作放到这里后，就不用每次都在功能区菜单里寻找。

适合加入快速访问工具栏的功能包括：

- 放大字体
- 缩小字体
- 格式刷
- 对齐工具
- 填充颜色
- 字体颜色

添加方式是：在某个功能按钮上点击右键，选择添加到快速访问工具栏。

如果某个功能不再常用，也可以在快速访问工具栏上右键删除。

快速访问工具栏默认可能显示在功能区上方。为了减少鼠标移动距离，建议将它显示在功能区下方。这样常用命令离编辑区域更近，操作效率更高。

#### 1.1.3 对齐与参考线

PPT 页面是否专业，最基础的判断之一就是元素是否对齐。新手不要依靠肉眼判断对齐，而要使用参考线和对齐工具。

**参考线**

`Alt + F9` 可以打开参考线。默认参考线通常是一条水平线和一条垂直线。

参考线的常见操作包括：

- 按住 `Ctrl` 拖动参考线，可以复制出新的参考线
- 将参考线拖出页面区域，可以删除参考线
- 跨页排版时，可以用同一组参考线保持页面元素位置一致

参考线特别适合处理跨页对齐。比如多页 PPT 都需要标题、正文或图片保持同一左边距，就可以用参考线统一位置。

**对齐按钮**

PPT 的对齐工具通常在：

```text
开始 -> 排列 -> 对齐
```

常用对齐方式包括：

- 左对齐
- 右对齐
- 顶端对齐
- 底端对齐
- 水平居中
- 垂直居中
- 横向分布
- 纵向分布

如果经常使用对齐工具，建议把它们添加到快速访问工具栏。这样选中多个对象后，可以直接点击按钮完成对齐或等距分布。

#### 1.1.4 选择窗格与对象层级

当页面中的元素很多，或者有半透明色块、图片、文字互相遮挡时，直接用鼠标点选会变得困难。此时需要使用选择窗格。

`Alt + F10` 可以打开选择窗格。它的作用类似图层面板，会列出当前页面中的所有对象。

选择窗格可以完成几类操作：

- 查看页面中所有对象的层级关系
- 直接选中某个被遮挡的对象
- 重命名对象，方便后续识别
- 点击小眼睛图标，临时隐藏或显示对象

当页面元素较少时，可以用置于顶层、置于底层、上移一层、下移一层调整对象层级。元素较多时，选择窗格更直观。

#### 1.1.5 组合与两把刷子

组合、格式刷和动画刷都是处理重复对象的重要工具。

**组合**

当多个元素共同组成一个局部模块时，可以先选中它们，再使用 `Ctrl + G` 组合。组合后可以统一移动、缩放和复制。

典型场景包括：

- 图标和文字说明组合
- 流程节点组合
- 装饰形状和标题组合
- 多个按钮或标签组合

**格式刷**

格式刷用于复制对象格式。选中一个已经设置好格式的对象，点击格式刷，再点击目标对象，就可以把格式刷过去。

如果只点击一次格式刷，它在刷完一个对象后会自动失效。如果需要连续刷多个对象，可以双击格式刷，让它保持启用状态；刷完后再点击一次格式刷取消。

格式刷适合统一：

- 形状填充
- 形状轮廓
- 阴影效果
- 字体样式
- 文本对齐方式

**动画刷**

动画刷用于复制动画效果。选中已经设置好动画的对象，点击动画刷，再点击其他对象，就可以把动画复制过去。

动画刷也可以双击后连续使用。多个对象需要统一动画效果时，不必逐个重新设置。

#### 1.1.6 绘制形状

PPT 的形状工具不只是画矩形和圆形，还可以通过合并形状和编辑顶点做出更灵活的图形。

**布尔运算**

布尔运算在 PPT 中对应“合并形状”工具。它用于对两个或多个形状进行几何关系处理。

常见合并形状方式包括：

- 联合：把多个形状合成一个整体
- 组合：保留非重叠区域，去掉相交部分
- 拆分：把重叠和非重叠区域拆成多个独立形状
- 相交：只保留多个形状共同重叠的区域
- 剪除：用后选中的形状从先选中的形状中裁掉一部分

布尔运算可以用基础形状做出复杂图形。比如两个圆可以通过剪除得到月牙形，也可以通过联合得到新的组合形状。

使用剪除时要注意选择顺序：先选中的形状通常是被保留和裁切的主体，后选中的形状用于参与剪除。

**编辑顶点**

插入形状后，可以右键选择编辑顶点，对形状轮廓进行自由调整。

编辑顶点可以完成：

- 移动已有顶点
- 添加新顶点
- 调整曲线手柄
- 切换顶点类型

常见顶点类型包括：

- 角部顶点
- 直线点
- 平滑顶点

编辑顶点适合在标准形状不能满足需求时使用。它可以把基础图形调整成更自由的曲线或不规则形状。

#### 1.1.7 本节总结

这一节的核心是补齐 PPT 软件操作基础。新手如果只靠鼠标慢慢拖，很容易低效且不稳定；掌握快捷键、快速访问工具栏、参考线、选择窗格和基础形状操作后，后续学习主题、模板、排版和图形设计会更顺畅。

本节最值得优先记住的操作是：

- `Ctrl + S` 随时保存
- `Ctrl + D` 快速复制
- `Ctrl + Shift` 平行复制
- `F4` 重复上一步
- `Alt + F9` 打开参考线
- `Alt + F10` 打开选择窗格
- `Ctrl + G` 组合对象
- `Ctrl + Alt + V` 选择性粘贴

### 1.2 全局化设计思维与 PPT 主题

这一节讲 PPT 设计中的全局化思维，以及 PowerPoint 中“主题”的概念。全局化设计的核心不是一页一页地硬改，而是先建立整套幻灯片的规则，让字体、颜色、版式和参考线在全篇中保持一致。

#### 1.2.1 先判断 PPT 的使用场景

开始做幻灯片之前，要先明确这份 PPT 的使用场景。不同类型的 PPT，设计重点完全不同。

常见的 PPT 可以先分成两类：

- 辅助演讲型
- 屏幕阅读型

这种分类比“教育培训类、项目投标类、工作总结类、学术报告类”等细分方式更实用。因为真正影响页面设计方式的，不是行业标签，而是这份 PPT 到底是“有人讲”，还是“别人自己看”。

**辅助演讲型 PPT**

辅助演讲型 PPT 是配合演讲者使用的幻灯片，例如发布会、公开讲座、课程演示等。

这类 PPT 的主体是演讲者，幻灯片只是辅助工具。因此页面可以很简洁，甚至只放一张图片、一组数据或一句核心文案，也不用担心观众看不懂，因为演讲者会现场解释。

辅助演讲型 PPT 常见做法包括：

- 使用高清大图
- 做图文混排
- 使用半透明形状遮罩
- 借助特殊字体增强视觉吸引力
- 每页只保留一个明确焦点

这类 PPT 更容易做出震撼感，因为页面信息少，视觉重点清楚。

**屏幕阅读型 PPT**

屏幕阅读型 PPT 是发给别人阅读的幻灯片，例如咨询报告、商业计划书、项目提案、工作汇报、数据报告等。

这类 PPT 没有人现场解释，页面本身必须承担完整的信息传递任务。因此内容往往更多，文字、数据、图表也更密集。

屏幕阅读型 PPT 的重点不是追求“漂亮”，而是先做到“专业”：

- 信息完整
- 结构清楚
- 版面规整
- 字体统一
- 色彩克制
- 阅读负担低

在工作场景中，经常会遇到页数限制、内容不能删、领导要求一个字都不能少等情况。这时不能简单套用“字越少越好”的原则，而要用设计方法让复杂内容看起来更清晰、更舒服。

#### 1.2.2 专业感来自统一、规整和简洁

专业咨询公司或市场调研公司的 PPT 报告通常看起来很统一，不一定是因为每一页都由设计师单独精修，而是因为内部有明确的幻灯片规范。

这些规范通常会规定：

- 字体
- 字号
- 行间距
- 色彩搭配
- 线条粗细
- 图表样式
- 版式规则

当有了统一的规则之后，不同人制作的页面也能保持一致。PPT 的专业感很大程度来自这种规范。

本节把专业 PPT 的基础规则概括为三点：

- 统一：整套幻灯片保持一致，包括字体、颜色、布局和排版
- 规整：页面元素严格对齐，布局有明确秩序
- 简洁：减少多余装饰，让内容更直接地呈现

这里的“简洁”不是把复杂内容删掉，也不是减少文字本身，而是在不减少信息的情况下，让页面更干净、更容易读。

#### 1.2.3 主题是全局化设计的基础

PowerPoint 中的“主题”是全局化设计的基础。它不是单独某一页的装饰，而是控制整套演示文稿视觉外观的一套规则。

按照微软的解释，主题用于为演示文稿提供设计师水准的外观，让所有幻灯片元素保持和谐一致。

可以把 PPT 主题理解为一套“皮肤”。它通常包括：

- 主题颜色
- 主题字体
- 背景样式
- 预设效果
- 预设版式

即使打开一个空白 PPT，它也已经带有默认主题。只是这个主题非常基础，默认的主题颜色和主题字体看起来不明显。

主题相关设置通常位于：

```text
设计 -> 主题 / 变体
```

在“变体”区域，可以对颜色、字体、效果和背景样式进行自定义。

#### 1.2.4 主题字体

主题字体决定了在当前 PPT 中输入文字时默认使用的字体。它是统一全文档字体的关键。

如果一页幻灯片里出现很多种字体，通常会显得杂乱。常见原因包括：

- 从其他地方复制内容时连同字体格式一起复制进来
- 手动给不同文本框设置不同字体
- 为了追求个性化而随意更换字体
- 没有提前设置全局主题字体

逐个文本框设置字体不仅浪费时间，也容易越改越乱。更专业的做法是先设置主题字体，让整套文档自动使用统一字体。

**设置建议**

一般情况下，可以分别为中文和西文设置字体。

比较稳妥的搭配是：

- 西文字体：`Arial`
- 中文字体：`微软雅黑`

如果是商业用途，还要注意字体版权。`微软雅黑` 本身也涉及版权问题，正式商业项目中需要谨慎处理。

设置好主题字体后，后续输入文字会自动适配中英文字体。字体设置应该尽量“一劳永逸”，而不是每个文本框单独设置。

**已有 PPT 的字体统一**

如果一份已有 PPT 中已经混用了很多字体，可以用两种方式统一。

第一种是 PowerPoint 自带的“替换字体”功能。它可以把一种字体替换为另一种字体，但局限是一次只能替换一种。如果文档里用了很多字体，就需要重复操作很多次。

第二种是使用 `iSlide` 的统一字体功能。它可以一次性把所有中文字体和英文字体分别统一成指定字体。

`iSlide` 统一字体通常有两种模式：

- 主题模式：只处理使用了主题字体规则的文字
- 强制模式：把所有文字强制统一为指定字体

如果原 PPT 没有按主题字体规则制作，可以先用强制模式统一一次。

**中文行间距**

PPT 默认的 `1.0` 倍行距更适合英文排版。中文段落如果行距太紧，阅读起来会吃力。

中文正文建议设置为：

- `1.2` 倍行距
- `1.3` 倍行距
- `1.5` 倍行距

具体数值要结合字号和版面密度调整。

#### 1.2.5 主题颜色

主题颜色提供了一种全局管理颜色的方法。设置好主题色后，整套 PPT 的形状、图表、表格和文字强调色都可以在这套颜色范围内选择。

颜色的作用主要有三类：

- 标识：体现品牌、行业或主题特征
- 区分：区分不同信息、类别或层级
- 强调：突出重点内容

很多新手会直接在颜色面板里随意挑颜色，结果越选越乱。正确做法是先定义主题色，再在主题色范围内选颜色。

**主题色的设置重点**

在主题颜色设置中，通常会看到 12 个颜色位。

其中更需要关注的是：

- 着色 1
- 着色 2
- 着色 3
- 着色 4
- 着色 5
- 着色 6

这 6 个颜色是 PPT 中形状、图表和表格最常用的主色。前面的文本与背景色、后面的超链接颜色一般可以先不重点处理。

**配色要克制**

色彩选择首先要克制。颜色越多，页面越容易显得杂乱。

与其临时随意选择颜色，不如使用现成的专业配色方案。常见来源包括：

- PPT 自带的配色方案
- `iSlide` 色彩库

使用 `iSlide` 色彩库时，可以选择设计师已经搭配好的配色方案，并一键应用到全部幻灯片。应用后，这套配色会成为当前 PPT 的主题色。

设置好主题色后，做页面时尽量只在主题色范围内取色。这样整套 PPT 会更统一，后续更换主题色时，也能实现全文档色彩的一键替换。

#### 1.2.6 版式与占位符

版式是 PPT 中另一个重要的全局化概念。它用于管理页面布局。

在幻灯片母版视图中，可以看到 PPT 默认提供的一些版式布局。对于经常重复出现的页面结构，可以把固定布局做成一个版式，然后多次应用。

版式中的虚线框叫占位符。占位符是在页面上预留内容位置，可以用于放置：

- 标题
- 正文
- 图片
- 图表
- 表格
- 媒体内容

占位符的价值在于先把布局做好，后续只需要填入内容。比如某个版式中已经预留了图片位置和两个文本区域，使用这个版式时直接点击占位符即可插入图片或输入文字。

#### 1.2.7 参考线与页面区域

参考线是让页面规整的重要工具。

打开参考线的快捷键是：

```text
Alt + F9
```

默认情况下，PPT 通常只有一条水平参考线和一条垂直参考线。按住 `Ctrl` 拖动参考线，可以复制出更多参考线。

通过参考线，可以把页面划分为几个区域：

- 标题区
- 内容区
- 页脚区

先规划区域，再放置内容，页面会更容易保持规整。参考线还可以帮助不同页面之间保持统一对齐。

需要注意的是，真正的参考线只在编辑时显示，放映时不会显示。

#### 1.2.8 为什么要使用主题

使用主题的最大好处可以概括为两个字：省事。

主题可以一次性管理整套 PPT 的视觉规则，包括字体、颜色、背景、版式和风格。更换主题时，也可以像换衣服一样快速切换整套 PPT 的外观。

但 PowerPoint 内置主题存在一个问题：数量有限，而且很多设计风格比较过时。因此实际使用中，通常不会直接套用内置主题。

更好的做法有两种：

- 自己设计并保存主题
- 使用 `iSlide` 等工具提供的主题库

`iSlide` 主题库中提供了较多现成主题，并且通常已经设置好主题配色、主题字体和常用版式。它还会精简和优化版式，只保留更实用的页面结构。

主题可以理解为整套 PPT 的衣服，而具体内容可以通过图示库、智能图表、图标库、图片库、插图库等继续补充。

#### 1.2.9 少用华丽预设效果

PowerPoint 中有很多预设效果，例如：

- 形状填充样式
- 发光
- 阴影
- 三维效果
- 图片效果
- 文字特效

新手很容易被这些看起来华丽的效果吸引，把各种效果都用到一份 PPT 中。结果往往会显得业余、不专业。

更稳妥的做法是：

- 抛弃多余特效
- 简化设计
- 直观呈现内容
- 先掌握 PPT 自身的规则
- 让全局化思维成为制作习惯

专业感不一定来自复杂效果，更多来自统一、规整和克制。

#### 1.2.10 本节总结

这一节的重点是建立全局化设计思维。做 PPT 时，不要只盯着单页好不好看，而要先建立整套文档的规则。

需要优先掌握的全局规则包括：

- 先判断 PPT 是辅助演讲型还是屏幕阅读型
- 工作型 PPT 要先追求专业，而不是单纯追求漂亮
- 专业感来自统一、规整和简洁
- 主题是 PPT 全局化设计的基础
- 主题字体用于统一全文档字体
- 主题颜色用于统一全文档配色
- 版式和占位符用于统一页面结构
- 参考线用于统一页面区域和跨页对齐
- 预设特效要克制使用，避免页面显得业余

### 1.3 你必须知道的 PPT 最基本操作

这一节继续补充 PPT 的基础操作，重点是几个做图和排版时几乎每天都会用到的功能。掌握这些操作后，很多重复性的调整可以明显变快，也能减少图片变形、元素错位、对象难以选中等常见问题。

#### 1.3.1 `Shift` 键：规则键

`Shift` 键在 PPT 中可以理解为“规则键”。按住它操作对象时，PPT 会帮助我们保持形状、比例或方向的规则性。

**绘制规则形状**

插入形状时，按住 `Shift` 可以绘制规则形状。

常见例子包括：

- 插入矩形时按住 `Shift`，可以得到正方形
- 插入椭圆时按住 `Shift`，可以得到正圆
- 插入三角形时按住 `Shift`，可以得到规则三角形
- 插入线条时按住 `Shift`，可以得到水平、垂直或 45 度方向的直线

如果不按 `Shift`，拖出来的圆形很容易变成椭圆，线条也容易出现轻微倾斜。

**等比例缩放**

调整对象大小时，按住 `Shift` 拖动角部控制点，可以保持对象的纵横比不变。

这个操作特别适合处理图片。如果直接拖动图片，很容易把人物或物体拉变形；按住 `Shift` 再缩放，可以保持图片比例。

**水平或垂直移动**

移动对象时，按住 `Shift` 可以限制对象只在水平或垂直方向移动。

当需要让对象沿着一条直线移动，或者微调图形位置时，这个操作很实用。

#### 1.3.2 `Ctrl` 键：复制与中心缩放

`Ctrl` 键在 PPT 中有两个常用作用：快速复制对象，以及从对象中心进行缩放。

**快速复制对象**

选中任意对象后，按住 `Ctrl` 拖动，就可以复制出一个新对象。

这个操作适用于：

- 单个形状
- 多个对象
- 图片
- 图标
- 文本框

如果同时按住 `Ctrl + Shift` 拖动，就可以沿水平或垂直方向复制对象。这个组合适合制作整齐排列的重复元素。

**从中心缩放对象**

调整对象大小时，按住 `Ctrl` 可以让对象以中心点为基准放大或缩小。

普通拖动通常只会从一个方向改变大小；按住 `Ctrl` 后，对象会从中心向两侧同时变化。横向拉伸、纵向拉伸和整体缩放都适用。

这个操作适合需要保持对象中心位置不变的场景。

#### 1.3.3 `Ctrl + G`：组合元素

当多个对象需要作为一个整体移动、缩放或复制时，可以把它们组合起来。

常用快捷键是：

- `Ctrl + G`：组合
- `Ctrl + Shift + G`：取消组合

如果不组合，多个对象一起缩放时，它们之间的相对位置可能会发生错乱。组合后，这些对象会作为一个整体被调整，内部元素之间的位置关系会保持不变。

常见做法是：

1. 先把一个小模块内部的元素组合起来
2. 再把多个小模块组合成更大的整体
3. 最后统一调整整体大小和位置

这种操作适合流程图、卡片组、图标说明、信息模块等结构。

#### 1.3.4 `Ctrl + Y`：重复上一步操作

`Ctrl + Y` 的功能是重做上一步操作。它和 `Ctrl + Z` 撤销相对应。

在 PPT 中，`Ctrl + Y` 很适合配合复制和组合使用。

例如制作一组矩形阵列：

1. 选中一个矩形
2. 按住 `Ctrl + Shift` 向右拖动，水平复制一个
3. 连续按 `Ctrl + Y`，重复刚才的水平复制
4. 选中这一排矩形，按 `Ctrl + G` 组合
5. 按住 `Ctrl + Shift` 向下拖动，复制出第二排
6. 连续按 `Ctrl + Y`，重复纵向复制

当页面中有多组重复信息时，可以先做好一组设计，再组合、复制、重复。这样比手动一个个复制和摆放更快。

需要注意的是，`Ctrl + Y` 取决于上一步操作是什么。如果上一步是撤销，那么 `Ctrl + Y` 会恢复撤销的步骤。

#### 1.3.5 选择窗格：PPT 的图层面板

PPT 中也有类似图层面板的功能，叫做选择窗格。

当页面中对象很多，或者下层对象被上层对象遮挡时，不需要先把上层对象移开。可以通过选择窗格直接选中和管理对象。

打开方式是：

```text
选中对象 -> 格式 -> 排列 -> 选择窗格
```

选择窗格可以完成几件事：

- 查看页面中所有对象
- 判断对象之间的上下层级关系
- 直接选中某个对象
- 拖动对象名称改变层级
- 点击小眼睛图标临时隐藏对象

如果一张图片被半透明形状盖住，可以在选择窗格中直接选中图片，也可以先临时隐藏上层形状，调整图片后再显示回来。

选择窗格适合处理对象较多、层级复杂的页面。

#### 1.3.6 恢复变形图片

图片在 PPT 中被拉伸后，经常会出现人物变胖、物体被压扁等变形问题。

如果图片已经变形，可以用裁剪中的填充功能恢复比例。

操作步骤是：

1. 选中变形图片
2. 打开图片格式菜单
3. 点击裁剪下拉选项
4. 选择填充
5. 拖动图片，调整合适的显示范围
6. 点击空白处完成裁剪

这样可以让图片恢复原始比例，同时保留当前占位区域。恢复比例后，可以继续调整图片在裁剪框中的显示位置。

这个方法适合修复被横向或纵向拉变形的图片。

#### 1.3.7 形状布尔运算

PPT 中的合并形状工具可以对多个形状进行布尔运算，从而得到 PPT 自带形状之外的新图形。

常见布尔运算包括：

- 联合
- 组合
- 拆分
- 相交
- 剪除

例如两个形状可以通过联合变成一个整体；也可以通过拆分，把相交部分和非相交部分拆成多个独立形状。

使用布尔运算时要先选中对象，否则合并形状菜单不会激活。

布尔运算的价值在于：不用完全依赖 PPT 默认形状，也能做出更灵活的图示。

#### 1.3.8 循环关系图示案例

课程用循环关系图示演示了布尔运算的实际用途。

大致流程是：

1. 从 PPT 自带形状中插入同心圆和尾形箭头
2. 复制出四个箭头
3. 调整四个箭头的方向和位置
4. 使用拆分或剪除得到需要的图形结构
5. 删除多余部分
6. 插入图片、图标和文字
7. 完成循环关系图示

如果使用拆分，通常还需要手动删除不需要的碎片，最后只保留想要的部分。

这个案例说明，布尔运算可以把基础形状改造成更复杂的关系图示。后续制作流程图、循环图、关系图和创意图形时，这个思路都可以复用。

#### 1.3.9 本节总结

这一节的核心是掌握 PPT 中最基础但很高频的操作。

优先记住这些功能：

- `Shift` 用于绘制规则形状、等比例缩放、水平或垂直移动
- `Ctrl` 用于快速复制对象，也可以从中心缩放对象
- `Ctrl + Shift` 适合水平或垂直方向复制对象
- `Ctrl + G` 用于组合对象
- `Ctrl + Shift + G` 用于取消组合
- `Ctrl + Y` 用于重复上一步操作
- 选择窗格用于管理复杂页面中的对象层级
- 裁剪中的填充可以恢复变形图片
- 合并形状可以通过布尔运算生成复杂图形

## 2. PPT 冷知识补习

这一部分整理了一组容易被忽略的 PPT 功能。它们不一定复杂，但在重复操作、文本排版和创意设计中很实用。理解这些功能后，不仅能提高效率，也能扩展做图和动画的思路。

### 2.1 神奇的 `F4` 键

`F4` 的作用是重复上一步操作。上一步完成了什么操作，再按一次 `F4`，PPT 就会重复执行同样的动作。

这里的 `F4` 指键盘顶部功能键区域中的一个按键。

#### 2.1.1 快速制作元素阵列

制作重复排列的元素时，可以配合 `Ctrl + Shift` 使用 `F4`。

例如制作矩形阵列：

1. 插入一个矩形
2. 按住 `Ctrl + Shift` 向右拖动，水平复制一个矩形
3. 保持新矩形处于选中状态，连续按 `F4`
4. 选中整排矩形，按住 `Ctrl + Shift` 向下拖动，复制出新的一排
5. 连续按 `F4`，继续向下复制

这样可以快速生成行列整齐、间距一致的元素阵列。

需要注意：复制出新对象后，要保持它处于选中状态。取消选择后再按 `F4`，可能不会产生预期效果。

#### 2.1.2 重复设置文字格式

`F4` 也可以重复格式设置。

例如一段文字中有多个关键词需要强调：

1. 选中第一个关键词
2. 设置文字颜色或其他格式
3. 选中下一个关键词
4. 按 `F4` 重复刚才的格式设置

这个操作和格式刷有些相似。格式刷更适合连续刷格式，`F4` 更适合快速重复最近一次操作。

#### 2.1.3 重复处理表格

处理表格时，`F4` 同样有用。

常见用途包括：

- 重复合并单元格
- 重复设置单元格底色
- 重复调整边框或文字格式

例如先选中几个单元格并执行合并，再选中其他单元格按 `F4`，就可以快速重复合并操作。

#### 2.1.4 本节总结

`F4` 是一个高效的重复操作键，适合处理：

- 元素阵列
- 文字格式
- 表格样式
- 重复合并

遇到重复劳动时，可以先尝试按一下 `F4`。

### 2.2 快速访问工具栏

快速访问工具栏用于集中放置常用命令。把高频功能放到编辑区附近，可以减少在多层菜单中来回寻找命令的时间。

#### 2.2.1 调整显示位置

快速访问工具栏默认通常位于界面左上角，只显示保存、撤销、放映等少量功能。

为了缩短鼠标移动距离，可以点击工具栏下拉菜单，选择：

```text
在功能区下方显示
```

这样工具栏会移动到功能区下方，更靠近幻灯片编辑区域。

#### 2.2.2 添加和删除命令

添加命令的方法很简单：

1. 在功能区中找到常用命令
2. 右键单击该命令
3. 选择添加到快速访问工具栏

如果不再需要某个命令，可以在快速访问工具栏中右键单击它，选择从快速访问工具栏删除。

适合添加的命令包括：

- 字体和字号设置
- 对齐工具
- 形状操作
- 图片裁剪
- 填充颜色
- 动画工具

对齐工具尤其值得加入工具栏。默认情况下，需要进入：

```text
开始 -> 排列 -> 对齐
```

添加后，选中对象就能直接执行左对齐、居中对齐、分布等操作。

#### 2.2.3 导入和导出工具栏配置

快速访问工具栏可以导出配置，也可以导入别人整理好的配置。

入口通常位于：

```text
文件 -> 选项 -> 快速访问工具栏 -> 导入或导出
```

不同 Office 版本的具体位置可能略有差异。

如果已经形成一套顺手的工具栏，可以将配置导出备份。更换电脑或重新安装 Office 后，导入配置即可恢复。

#### 2.2.4 精简编辑界面

常用命令都放入快速访问工具栏后，可以把功能区设置为只显示选项卡。这样界面会更简洁，幻灯片编辑区域也会更大。

#### 2.2.5 本节总结

快速访问工具栏的价值是减少查找命令的时间。

建议：

- 显示在功能区下方
- 优先加入高频命令
- 定期增删和优化
- 导出配置作为备份

### 2.3 你真的了解 PPT 文本框吗

文本框是 PPT 中最常见的元素之一，但很多细节容易被忽略。

#### 2.3.1 文本框和形状本质相近

文本框和形状可以理解为同一类对象：

- 文本框可以设置填充和边框
- 形状内部也可以直接输入文字
- 两者右键打开设置形状格式后，设置项基本一致

文本框可以理解为默认没有填充色和边框的形状；形状也可以理解为带有外观样式的文本框。

因此，不要在形状上面额外叠加一个文本框再输入文字。更高效的做法是直接在形状内部输入文字，统一调整形状和文本。

#### 2.3.2 文本框的自动调整方式

文本框和形状看起来行为不同，主要是因为默认的文本框选项不同。

常见设置包括：

- 根据文字调整形状大小
- 溢出时缩排文字
- 不自动调整

“根据文字调整形状大小”会让文本框随着文字变化，因而不容易自由拉高。

“溢出时缩排文字”会在文字超出边界时自动缩小字号，避免内容溢出。

能否自由调整大小，不取决于对象是文本框还是形状，而取决于选择了哪一种自动调整方式。

#### 2.3.3 文本的九种对齐方式

文字不只有左对齐、居中对齐、右对齐，还可以设置垂直方向上的对齐。

水平方向包括：

- 左对齐
- 居中对齐
- 右对齐

垂直方向包括：

- 顶端对齐
- 中部对齐
- 底端对齐

组合起来，一共有九种对齐方式。

对齐方式要在一开始就设置好。如果后期才修改，往往要重新调整文本框位置和页面布局。

#### 2.3.4 文本框边距

有时文本框已经和其他对象严格对齐，但文字看起来仍然没有对齐。这通常是因为文本框内部存在默认边距。

解决方法是：

1. 选中文本框
2. 打开设置形状格式
3. 进入文本选项中的文本框设置
4. 将上下左右边距设为 `0`

如果使用 `iSlide`，可以通过设计工具中的删除边距快速清零。

#### 2.3.5 本节总结

文本框不是只能输入文字的简单容器。

需要记住：

- 文本框和形状本质相近
- 文字可以直接写在形状里
- 自动调整方式决定对象大小行为
- 文本有九种对齐方式
- 边距会影响严格对齐

### 2.4 PPT 文本框的高阶玩法

文本框不仅能排版文字，还可以结合文字效果、字符、形状和图片做出更有创意的视觉元素。

#### 2.4.1 文字转换效果

入口通常位于：

```text
形状格式 -> 文本效果 -> 转换
```

转换菜单中包含圆形、波形、不规则圆、梯形等效果。选中文本框后应用这些效果，文字会沿指定路径发生形变。

这些效果操作简单，但组合不同字符后可以产生很多变化。

#### 2.4.2 用特殊符号制作装饰元素

字符不一定是普通文字，也可以是特殊符号。

例如制作心形环绕图案：

1. 插入一个形状
2. 取消填充色和边框
3. 设置字体颜色
4. 双击进入文字输入状态
5. 插入心形符号
6. 使用 `F4` 重复插入多个符号
7. 应用圆形转换效果

同样的思路也适用于：

- 三角形
- 短横线
- 斜线
- 左右括号
- 尖括号
- 几何符号

字符不同、数量不同、转换样式不同，最终效果也会不同。

#### 2.4.3 空心字和实心字组合

一组字符可以分别设置文字填充和文字轮廓。

例如把一半短横线设置为只有文字轮廓，另一半设置为同时有轮廓和填充，再应用圆形转换效果，就能得到一半空心、一半实心的环形图案。

#### 2.4.4 将文字矢量化后填充图片

字符经过转换后，仍然属于文字。通过 `iSlide` 的文字矢量化工具，可以将它转换成形状。

后续可以：

1. 调整矢量形状的大小和位置
2. 右键打开设置形状格式
3. 选择图片或纹理填充
4. 插入图片

这样可以把图片放进由文字转换得到的特殊轮廓中，用于封面或装饰设计。

如果字符之间间距过大，可以在字符间距中设置为紧密或很紧。

#### 2.4.5 让文字贴合背景

文本转换也可以用于让标题和背景更自然地融合。

例如在有透视感的背景图上，可以给文字应用梯形转换，再调整黄色控制点，使文字方向更贴近背景结构。

#### 2.4.6 本节总结

文本框高阶玩法的关键不是记住某一个案例，而是理解组合思路：

```text
字符 -> 转换效果 -> 字符间距 -> 矢量化 -> 图片填充或动画
```

多尝试不同字符和转换样式，往往比照抄案例更有价值。

### 2.5 有趣的文本框动画

文本框动画的关键在于：动画不一定只能让整个文本框一起出现，也可以让文字按词或按字母依次出现。

#### 2.5.1 按字母播放动画

给文本框添加动画后，可以在动画窗格中打开效果选项。

动画文本通常有三种方式：

- 一次性显示全部
- 按词播放
- 按字母播放

选择按字母后，文字会逐字出现，还可以调整字母之间的延迟。

部分动画还可以调整起点，例如从对象中心或幻灯片中心开始。

#### 2.5.2 用图片填充文字

文本填充和形状填充是两个不同概念：

- 形状填充：给文本框或形状本身填充颜色或图片
- 文本填充：给文本框内部的文字填充颜色或图片

将文字设置为图片填充后，再结合按字母动画，就能让图片随着字符逐步出现。

一种常见做法是：

1. 插入文本框
2. 输入一组短横线
3. 应用正方形、波形或其他转换效果
4. 将字符间距设置为很紧
5. 给文字填充图片
6. 添加缩放、飞入或浮动动画
7. 在效果选项中设置按字母播放

还可以为动画添加弹跳结束，使出现过程更有动感。

#### 2.5.3 制作循环加载动画

文本框也可以用来制作加载动画。

基本流程是：

1. 插入文本框
2. 输入多个小圆点
3. 每个圆点单独占一行
4. 将行距设置为固定值 `0`
5. 添加圆形动作路径
6. 在效果选项中设置按字母播放
7. 调整动画时长
8. 将重复设置为直到幻灯片末尾

多个圆点会沿路径依次运动，看起来像持续循环的加载动画。

不同字体中的圆点形状可能不同。如果显示为方形，可以更换字体，选择更接近圆形的效果。

#### 2.5.4 不要被案例限制思路

同一种原理可以产生很多变化：

- 更换字符
- 更换文字转换效果
- 更换图片
- 更换动画类型
- 调整播放方向
- 调整时长和延迟
- 调整循环次数

课程案例的意义是说明原理，不是规定唯一做法。

#### 2.5.5 本节总结

文本框动画的核心组合是：

```text
字符 -> 文本转换 -> 文本填充 -> 按字母动画 -> 时长和循环设置
```

掌握这个思路后，可以制作图片揭示动画、装饰动效和循环加载动画。

## 3. PPT 图片排版

图片排版是 PPT 设计中的常见任务。图片不仅承担内容展示的作用，也可以作为辅助性的视觉元素。处理图片时，首先要判断图片的用途，再选择合适的排版方式。

### 3.1 图片的用途和多图排版

#### 3.1.1 汇报型 PPT 优先考虑实用性

日常工作和学习中常见的是汇报型 PPT，而不是科技发布会式的演讲型 PPT。图片排版需要服务于信息表达，不必追求复杂、夸张的视觉效果。

适合日常汇报的图片排版通常具备以下特点：

- 页面结构清晰
- 图片规格统一
- 元素排列整齐
- 视觉效果克制
- 文字容易阅读

中英文排版的底层逻辑基本一致。英文段落有时看起来更舒展，主要是因为中英文字体的字高和默认行距不同。中文段落可以适当增大行距，推荐使用 `1.2` 到 `1.5` 倍行距。

#### 3.1.2 图片作为内容

当图片本身需要被观众重点识别时，图片承担的是内容表达功能。例如：

- 产品展示
- 软件截图
- 人物介绍
- 团队成员介绍
- 案例对比

内容型图片的处理原则可以概括为三个关键词：

1. 简洁
2. 统一
3. 整齐

**简洁**：不要堆叠阴影、发光、三维效果和柔化边缘等装饰。图片本身已经是内容主体，过度修饰反而会分散注意力。

**统一**：同一页中的图片尽量使用一致的形状、大小和样式。这里强调的是单页内部统一，不是要求整份文档中的所有图片完全一致。

**整齐**：通过对齐工具实现严格对齐，不依赖肉眼观察和手动拖动。横向间距和纵向间距也要保持一致。

#### 3.1.3 图片作为修饰

当图片不承担主要信息表达任务，而是用于丰富画面或增强设计感时，图片属于修饰性元素。例如：

- 全图背景
- 半图构图
- 页面边缘装饰
- 文字区域旁的辅助图片

修饰型图片需要保持低调，避免抢夺前景内容的注意力。常见处理原则包括：

- 选择简单、干净、通透的图片
- 降低图片的视觉强度
- 根据构图需要适当裁剪
- 避免拉伸和挤压变形
- 保证前景文字容易阅读

#### 3.1.4 多图排版的基本规则

多图排版需要重点关注三个细节：

1. 统一规格
2. 正常比例
3. 规则排列

**统一规格**：同一页中的图片在形状、大小和样式上保持一致。

**正常比例**：图片不能发生拉伸、压缩和变形。如果图片比例不合适，应使用裁剪功能调整显示区域。

**规则排列**：使用对齐和分布工具，让图片严格排列。页面中的间距应保持一致。

多图排版的实用流程是：

```text
统一图片尺寸和形状 -> 恢复图片比例 -> 调整显示区域 -> 对齐 -> 均匀分布
```

#### 3.1.5 本节总结

- 图片作用有两种，作为内容和修饰。
- 内容为主需谨记，简洁、统一和整齐。
- 摒弃华丽的修饰，简单、干净记心里。
- 形状大小要统一，严格对齐排第一。
- 作为修饰要低调，拉伸变形不可以。
- 多图排版要专业，统一、对齐须留意。

### 3.2 通过形状占位法设计图片排版

#### 3.2.1 先排版，再填充图片

直接将多张图片拖入 PPT 后，需要逐一调整大小和位置，效率较低。更实用的方法是先使用形状完成版面设计，再将图片填充到形状中。

形状占位法的核心流程是：

```text
插入形状 -> 完成占位排版 -> 将图片填充到形状 -> 裁剪并调整显示区域
```

需要方形图片就插入正方形，需要圆形图片就插入圆形。也可以根据版面需要使用长方形、菱形、平行四边形或其他形状。

#### 3.2.2 使用 PowerPoint 原生功能填充图片

使用 PowerPoint 原生功能时，操作步骤如下：

1. 选中目标形状
2. 右键选择“设置形状格式”
3. 在填充选项中选择“图片或纹理填充”
4. 在图片源中选择“插入”
5. 选择“来自文件”
6. 插入目标图片
7. 在“图片格式”中打开“裁剪”
8. 选择“填充”
9. 拖动图片，调整显示区域

图片插入形状后可能出现拉伸或挤压。此时选择“裁剪”中的“填充”，即可恢复图片的正常比例。

#### 3.2.3 使用 iSlide 图片库提高效率

使用 iSlide 图片库时，操作更加直接：

1. 选中目标形状
2. 打开 iSlide 图片库
3. 点击需要使用的图片

图片会直接填充到当前形状中，并且不会发生挤压变形。如果需要替换图片，保持形状选中，再点击另一张图片即可。

自己的图片也可以上传到图片库，并添加检索关键词，方便以后重复使用。

#### 3.2.4 处理异形图片

形状占位法特别适合处理异形图片。例如：

- 墨迹形状
- 圆形头像
- 平行四边形图片
- 不规则装饰图形

异形图片的本质不是直接将图片裁剪成复杂轮廓，而是先制作一个目标形状，再使用该形状限制图片的显示区域。

这种方式降低了图片处理难度，也方便后续替换图片。

#### 3.2.5 恢复变形图片

当图片为了适应占位区域而发生拉伸或挤压时，可以使用“裁剪”菜单中的“填充”命令恢复比例。

调整步骤如下：

1. 选中图片
2. 打开“图片格式”
3. 点击“裁剪”
4. 选择“填充”
5. 拖动图片，调整显示区域
6. 按住 `Shift` 并拖动控制点，等比例缩放图片

裁剪不会立即删除超出区域的图片内容，而是将其隐藏起来。后续仍然可以重新调整显示区域。

#### 3.2.6 本节总结

- 图片插入有妙招，形状占位来设计。
- 先做排版后插图，填充替换都随你。
- 异形图片怎么做，图片插入形状里。
- 恢复变形有绝招，裁剪填充原比例。

### 3.3 图片作为背景时的处理方法

背景图片属于修饰性元素。它的作用是丰富画面，而不是成为视觉焦点。处理背景图片时，需要让它保持低调，确保前景文字和核心内容足够清晰。

常用处理方法包括：

1. 添加半透明遮罩
2. 降低饱和度
3. 虚化图片
4. 裁剪图片
5. 让图片与背景融合

#### 3.3.1 添加半透明遮罩

当背景图片较复杂，前景文字不易阅读时，可以在图片和文字之间添加一个半透明色块。

页面的图层关系如下：

```text
前景文字
半透明形状
背景图片
```

操作步骤如下：

1. 插入矩形
2. 将矩形调整到与背景图片等大
3. 设置为无轮廓
4. 将矩形放在图片上方、文字下方
5. 右键选择“设置形状格式”
6. 设置填充颜色
7. 调整透明度

透明度没有固定值，需要根据图片复杂程度和文字清晰度反复调整。课程案例中约 `40%` 的透明度较为合适，但实际使用时应以视觉效果为准。

可以使用 `Alt + F10` 打开选择窗格，调整图片、遮罩和文字之间的层级关系。

#### 3.3.2 降低图片饱和度

如果背景图片的色彩倾向与当前 PPT 的主题色不协调，可以降低饱和度，让图片更加克制。

操作步骤如下：

1. 选中图片
2. 打开“图片格式”
3. 点击“颜色”
4. 选择合适的饱和度预设
5. 如有需要，打开“图片颜色选项”
6. 手动调整饱和度

饱和度不一定必须降到 `0%`。可以根据原始图片和页面主题色选择合适的值。

#### 3.3.3 虚化背景图片

虚化可以弱化背景细节，让前景内容更加突出。

操作步骤如下：

1. 选中图片
2. 打开“图片格式”
3. 点击“艺术效果”
4. 选择虚化效果
5. 打开“艺术效果选项”
6. 调整虚化半径

虚化半径同样没有统一参数。背景细节越复杂，通常越需要适当提高虚化程度。

#### 3.3.4 裁剪图片并重新构图

图片作为背景时，原始显示区域不一定适合页面构图。例如，人物可能被不自然地截断，或者视觉重心落在错误的位置。

推荐的处理方式是：

1. 选中图片
2. 打开“图片格式”
3. 点击“裁剪”
4. 选择“填充”
5. 拖动图片，调整显示区域
6. 点击空白处完成裁剪

裁剪的目的不只是删除多余内容，也是对图片进行二次构图。

#### 3.3.5 让图片与背景自然融合

当图片没有铺满整个页面时，图片边缘可能与背景之间形成突兀的分界线。可以在图片上方覆盖一个渐变填充形状，让图片逐渐过渡到背景色。

基本原理是：

```text
一端为背景色且不透明 -> 中间渐变过渡 -> 另一端完全透明
```

操作步骤如下：

1. 插入一个覆盖图片边缘的形状
2. 设置为无轮廓
3. 选择“渐变填充”
4. 删除不需要的渐变光圈
5. 保留至少两个渐变光圈
6. 将颜色设置为与背景一致
7. 将一端透明度设置为 `0%`
8. 将另一端透明度设置为 `100%`
9. 调整渐变方向
10. 调整渐变光圈的位置，直到边界自然消失

渐变光圈的位置和数量没有固定参数，需要根据图片边缘和背景色反复调整。

#### 3.3.6 本节总结

- 图片用作背景时，常用手法有五种。
- 遮罩、去色和虚化，还有裁剪和融合。
- 遮罩覆盖半透明，去色降低饱和度。
- 虚化减弱背景图，前景内容被突出。
- 裁切图片去多余，恢复变形也可以。
- 图片背景相融合，添加透明渐变层。
- 渐变光圈不固定，根据需要来调整。
