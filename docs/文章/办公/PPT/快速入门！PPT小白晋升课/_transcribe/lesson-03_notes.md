# 第 3 课：全局化主题模板设计（上）

这一节开始进入主题模板的实际设计。课程先补充主题字体和主题颜色的设置原则，然后演示如何进入幻灯片母版视图、清理无用版式，并说明母版版式如何应用到普通编辑页面。

## 3.1 主题字体的设置建议

主题字体不建议设置得太复杂。一般只需要设置两类字体：

- 中文字体
- 西文字体

这样做的好处是整套 PPT 的文字风格更统一，也方便后续批量替换。

正式文件中更建议使用系统自带字体。原因是 PPT 文件经常需要传给别人，如果使用了对方电脑没有安装的特殊字体，打开后就可能出现字体丢失、版面错乱或视觉效果变差的问题。

如果确实需要使用特殊字体，可以考虑把字体嵌入到 PPT 文件中。`.pptx` 格式支持把字体等资源压缩嵌入文件内部，但为了减少兼容性问题，常规课程作业或正式汇报文件仍然优先使用系统字体。

## 3.2 主题颜色的设置建议

设置主题颜色时，不需要把所有颜色都改掉。比较稳妥的做法是：

- 文字和背景的四个颜色保持默认
- 着色 1 到着色 6 设置为当前 PPT 需要的主题色
- 超链接和已访问超链接颜色保持默认，或设置成明显区别于着色 1 到着色 6 的颜色

文字和背景颜色承担的是基础可读性。如果随意修改，可能会影响页面对比度和阅读体验。真正用于统一页面风格的，主要是着色 1 到着色 6。

如果自己不擅长配色，可以借助 `iSlide` 的色彩库。选择一套配色后，将它应用到全部页面，再根据需要微调其中某一个主题色。

## 3.3 设置主题字体

标准流程是先设置主题字体，再设置主题颜色。主题字体的入口在：

```text
设计 -> 变体 -> 字体 -> 自定义字体
```

打开自定义字体后，需要分别设置西文字体和中文字体。课程中给出的示例是：

- 西文字体：`Arial`
- 中文字体：微软雅黑

设置完成后保存，这套字体就会应用到当前 PPT。后续新增文本或使用占位符时，会优先沿用这套主题字体。

## 3.4 设置主题颜色

主题颜色的入口在：

```text
设计 -> 变体 -> 颜色 -> 自定义颜色
```

进入主题颜色编辑框后，重点修改着色 1 到着色 6。背景色、文字色、超链接色可以保持默认，除非有明确的设计需求。

如果使用 `iSlide` 色彩库，可以先选择一套推荐配色，应用到全部页面，再进入编辑状态修改具体颜色。比如某个颜色不符合当前主题，可以通过编辑按钮打开颜色设置，再使用吸管工具吸取需要的颜色并保存。

## 3.5 什么是幻灯片母版

幻灯片母版可以理解为 PPT 的全局版式管理区域。它不是普通编辑页面，而是用来定义页面结构、占位符、标题位置、背景、页脚和默认排版规则的地方。

打开方式是：

```text
视图 -> 幻灯片母版
```

进入母版视图后，左侧会显示微软默认提供的一系列版式。这些版式包含标题页、标题和内容、两栏内容、比较、仅标题等默认排版。

## 3.6 清理无用版式

默认母版中有很多版式并不一定会用到。如果全部保留，后面选择版式时会很混乱。

课程建议先删除不需要的默认版式，只保留常用版式。删除方式有两种：

- 选中版式后右键删除版式
- 选中版式后按 `Delete`

清理后的母版会更简洁，后续制作 PPT 时也更容易找到真正需要的页面类型。

## 3.7 母版版式和普通编辑页面的关系

在母版视图中添加的内容，不会立刻直接显示在当前普通编辑页面上。母版里的设计需要通过“应用版式”才能作用到某一页 PPT。

操作逻辑是：

```text
视图 -> 幻灯片母版
-> 在某个版式中添加元素
-> 关闭母版视图
-> 右键当前幻灯片
-> 版式
-> 选择刚刚编辑过的版式
```

应用之后，母版中定义的元素才会出现在当前幻灯片中。新建幻灯片时，如果也想使用同样的结构，同样需要右键选择对应版式。

## 3.8 本节总结

本节课的重点是把“主题设置”和“母版版式”连接起来。主题字体和主题颜色负责统一视觉风格，幻灯片母版负责统一页面结构。

实际制作时，可以按照这个顺序操作：

1. 先设置主题字体
2. 再设置主题颜色
3. 进入幻灯片母版
4. 删除不需要的默认版式
5. 保留或设计常用版式
6. 回到编辑页面后，通过“版式”应用母版设计

这样制作出来的 PPT 才更接近标准化的主题模板，而不是单纯复制几个设计好的页面。
