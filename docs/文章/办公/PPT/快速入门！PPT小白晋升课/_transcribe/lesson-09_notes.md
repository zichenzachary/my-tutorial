## 9. PPT 的高级作图操作（上）

### 9.1 本节核心

高级作图不是脱离基础形状重新学习一套工具，而是把圆形、矩形、三角形、箭头等基础图形组合起来，做出更复杂的图示结构。

本节重点包括：

- 用基础形状组合高级图示
- 使用 iSlide 环形布局
- 使用矩阵裁切制作金字塔图示
- 制作流程类图示
- 制作 Logo 墙
- 制作创意图片填充
- 回顾对齐工具和大小工具

### 9.2 圆环叠加图示

圆环叠加图示可以用多个圆形组合完成。

基本思路：

1. 插入一个圆形，去掉边框。
2. 将设置好的形状设为默认形状，后续绘制新圆形时就不会重复出现边框。
3. 再绘制一个圆形，设置为红色边框、无填充。
4. 将两个圆形水平居中、垂直居中。
5. 复制圆环，并按住 `Ctrl + Shift` 做等比例中心缩放。
6. 调整线宽、虚线样式和辅助圆的位置。

如果手动复制多个圆形并围绕圆心排布，很难做到均匀。更高效的方法是使用 iSlide 的环形布局。

### 9.3 iSlide 环形布局

iSlide 的环形布局可以把对象按圆形路径均匀排布。

操作思路：

```text
选中对象 -> 打开 iSlide 环形布局 -> 设置数量 -> 调整半径 -> 应用
```

例如只保留一个小圆，选中它后打开环形布局，设置数量为 6，再调整布局半径，就可以快速得到均匀分布的六个小圆。

这个方法适合制作：

- 圆环图示
- 循环关系
- 环绕式结构
- 中心扩散关系
- 多点围绕中心的展示页

### 9.4 倒金字塔图示

倒金字塔可以用三角形和 iSlide 的矩阵裁切快速完成。

低效做法是用梯形和三角形逐个拼接，但最后容易出现对不齐、间距不一致、形状不好拼的问题。

更快的做法：

```text
插入三角形 -> 选中三角形 -> iSlide 设计排版 -> 矩阵裁切 -> 设置纵向数量 -> 调整间距 -> 应用
```

例如把纵向数量设置为 4 或 5，再把间距设置为合适比例，就可以快速得到分层金字塔结构。

适用场景包括：

- 层级递进
- 重要性排序
- 结构分层
-  funnel / 金字塔类模型

### 9.5 流程图示

流程图示可以用箭头和流程图形状组合完成。

基本步骤：

1. 插入箭头图形。
2. 插入流程图中的辅助形状。
3. 调整颜色和大小。
4. 使用 `Ctrl + G` 组合成一个单元。
5. 使用 `Ctrl + D` 复制多个单元。
6. 继续按 `Ctrl + D`，让后续单元按相同距离连续复制。
7. 使用 iSlide 的智能参考线或对齐工具统一布局。

这种方法适合制作横向流程、步骤说明、阶段递进等页面。

### 9.6 参考线布局

在复杂图示中，参考线可以帮助元素快速贴合页面区域。

常用操作包括：

- 顶端对齐到参考线
- 左端对齐到参考线
- 扩展到参考线范围
- 左右扩展
- 横向分布
- 纵向分布

如果页面已经建立了参考线，iSlide 可以帮助对象快速对齐到参考线或扩展到参考线范围，比手动拖拽更稳定。

### 9.7 Logo 墙

Logo 墙可以用六边形等基础形状组合制作。

基本步骤：

1. 插入六边形。
2. 按住 `Shift` 绘制正六边形。
3. 调整第一个六边形的位置和大小。
4. 按住 `Ctrl` 拖动复制多个六边形。
5. 使用 `Ctrl + 方向键` 微调位置。
6. 完成整体布局后，用 `Ctrl + G` 组合。
7. 按住 `Shift` 等比例缩放整体。
8. 调整部分形状颜色，形成层次。
9. 使用 iSlide 图标库下载图标，将图标放入对应位置。

课程中用图标代替企业 Logo 演示。实际使用时，可以把图标替换为学校、学院、企业或项目相关标识。

### 9.8 创意图片填充

创意图片填充可以先用多个矩形组成一个版面结构，再给整体填充图片。

基本步骤：

1. 插入一个矩形。
2. 按住 `Ctrl` 拖动复制多个矩形。
3. 框选所有矩形，进行横向分布。
4. 根据间距调整最外侧矩形位置。
5. 重新横向分布，让间距更均匀。
6. 选中全部矩形并 `Ctrl + G` 组合。
7. 在形状填充中选择“图片或纹理填充”。
8. 选择合适图片插入。

直接给单个矩形填充图片时，图片可能被压缩变形。可以通过：

```text
图片格式 -> 裁切 -> 填充
```

让图片恢复正常比例。

当多个形状组合后统一填充图片时，可能还需要在效果选项中勾选“将图片平铺为纹理”。不过这节课也提到，若想更灵活地控制图片主体位置，后续会用布尔运算解决。

### 9.9 对齐工具和大小工具

本节最后回顾了 iSlide 的对齐工具和大小工具。

大小统一的操作方式：

```text
先选中需要调整的对象 -> 按住 Shift 选中目标大小对象 -> 点击等大小
```

对齐和分布常用操作：

- 右对齐
- 左对齐
- 顶端对齐
- 底端对齐
- 横向分布
- 纵向分布

这些工具在图示制作中非常常用，尤其适合批量处理一组形状。

### 9.10 本节总结

本节的重点是把基础图形组合成高级图示。

- 高级作图依然建立在基础形状、快捷键、对齐和分布操作上。
- iSlide 的环形布局适合制作循环、环绕和多点分布图示。
- 矩阵裁切可以快速制作金字塔、分层结构等图示。
- `Ctrl + D` 适合连续复制流程类图示单元。
- Logo 墙和创意图片填充都可以通过形状组合实现。
- 对齐工具和大小工具是提高图示制作效率的关键。
