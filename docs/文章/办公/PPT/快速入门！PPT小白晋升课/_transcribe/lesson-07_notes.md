## 7. PPT 的基本作图操作（上）

### 7.1 本节核心

本节开始进入 PPT 的基础作图操作。这里的“作图”不是复杂绘画，而是用 PPT 自带的形状工具绘制、组合和调整基础图形，让页面内容可以用图形化方式表达。

本节重点包括：

- 认识 PPT 常用形状工具
- 设置快速访问工具栏
- 使用 `Shift` 键绘制标准图形
- 使用 `Shift` 键控制移动、绘制和旋转角度

### 7.2 常用形状工具

PPT 的形状工具位于“插入”中的形状菜单，常用形状包括：

- 圆形
- 矩形
- 圆角矩形
- 三角形
- 六边形
- 线条
- 曲线
- 自由多边形
- 流程图形状

其中一些形状带有黄色控制点，可以进一步调整形状结构。例如圆角矩形可以通过黄色控制点改变圆角大小，部分流程图或特殊形状也可以通过控制点调整形态。

在实际制作 PPT 时，常用形状并不复杂。高频操作通常围绕圆形、矩形、圆角矩形、线条和少量特殊形状展开。重点不在于记住所有形状，而在于熟练掌握形状的绘制、复制、对齐、组合和缩放。

### 7.3 快速访问工具栏

快速访问工具栏可以把高频功能放到更容易点击的位置，减少在菜单栏中反复查找工具的时间。

普通操作流程通常比较长。例如：

```text
插入 -> 形状 -> 选择形状
形状格式 -> 对齐 -> 选择对齐方式
形状格式 -> 合并形状 -> 选择组合方式
形状格式 -> 旋转 -> 选择翻转方式
```

如果把这些常用命令放入快速访问工具栏，就可以直接点击工具完成操作。

常用加入快速访问工具栏的功能包括：

- 插入常用形状
- 对齐工具
- 合并形状
- 旋转与翻转
- 形状格式
- 图片裁切
- iSlide 常用工具

### 7.4 设置快速访问工具栏

添加工具的方法很简单：

```text
找到需要添加的功能 -> 右键 -> 添加到快速访问工具栏
```

例如，可以把 iSlide 中的主题字体、对齐工具、设计工具等加入快速访问工具栏。添加完成后，该工具会出现在快速访问工具栏中。

默认情况下，快速访问工具栏可能显示在功能区上方。为了让它更靠近编辑区域，可以把它移动到功能区下方：

```text
右键工具栏 -> 在功能区下方显示快速访问工具栏
```

这样操作距离更短，做图、排版和调整时会更顺手。

### 7.5 `Shift` 键的作用

在 PPT 作图中，`Shift` 可以理解为“规则键”。按住 `Shift` 后，PPT 会按照更规则的方式绘制、缩放、移动或旋转对象。

`Shift` 的常用作用包括：

- 绘制正圆、正方形、正三角形、正六边形
- 等比例放大或缩小图形
- 沿水平或垂直方向移动对象
- 按 45 度角绘制线条
- 按 15 度角旋转对象

### 7.6 绘制标准图形

直接拖动画圆时，很容易画成椭圆。按住 `Shift` 再拖动，就可以绘制正圆。

同理：

- 绘制矩形时按住 `Shift`，得到正方形
- 绘制三角形时按住 `Shift`，得到正三角形
- 绘制六边形时按住 `Shift`，得到正六边形

这个方法适用于大多数规则形状。只要希望图形保持标准比例，绘制时就应优先按住 `Shift`。

### 7.7 等比例缩放

缩放图形时，如果不按 `Shift`，图形可能被横向或纵向拉伸，导致比例变形。

按住 `Shift` 后再拖动缩放点，图形会按原比例放大或缩小。这个操作对形状和图片都很重要，尤其是在处理图片时，可以避免人物、图标或照片被拉变形。

适用场景包括：

- 放大或缩小图标
- 调整照片大小
- 调整组合图形
- 保持圆形、正方形等图形不变形

### 7.8 直线移动

移动对象时，直接拖动容易产生轻微偏移。按住 `Shift` 后拖动，对象会沿水平或垂直方向移动。

这个功能适合用于：

- 把对象平移到页面另一侧
- 保持多个元素在同一水平线上
- 保持多个元素在同一垂直线上
- 复制和排版时避免对象上下错位

### 7.9 按角度绘制和旋转

绘制线条时，按住 `Shift` 可以让线条按照固定角度变化，常见角度包括：

- 0 度
- 45 度
- 90 度
- -45 度

旋转对象时，按住 `Shift` 可以按 15 度为单位旋转。这样可以更精确地控制角度，避免对象出现不规则倾斜。

### 7.10 本节总结

本节主要解决的是 PPT 作图的基础效率问题。

- 快速访问工具栏用于减少菜单查找，提高高频操作速度。
- 常用形状是 PPT 图形化表达的基础，不需要追求复杂，关键是熟练使用。
- `Shift` 是作图时非常重要的规则键，可以帮助绘制标准图形、等比例缩放、直线移动和固定角度旋转。
- 后续进行图文排版、图示制作和高级组合图形时，这些基础操作会被反复使用。
