# 第 1 课：PPT 主题模板的概念（上）

这一节是整套课程的入口，主要讲两个问题：为什么要学习“全局化主题模板”，以及传统意义上的 PPT 模板为什么经常不好用。

## 1.1 课程整体内容

这门课围绕 PPT 从基础到输出的完整流程展开，主要包括七个模块：

- 全局化主题模板概念
- 全局化主题模板设计
- PPT 大纲视图的使用
- PPT 的基本作图操作
- PPT 的高级作图操作
- 图示图表的制作
- PPT 的保存与导出

## 1.2 什么是全局化主题模板

在 PPT 里，“全局化”可以理解为：按照微软官方定义的规则，制作一套标准化的 PPT 模板。

这类模板不是简单把几个页面排好看，而是让整套 PPT 具备统一的全局规则，例如主题色、主题字体、母版、版式和文本层级。

## 1.3 全局化设计的价值

按照标准流程制作的 PPT，可以支持一键换色、一键调整字体等操作。

操作路径大致是：

```text
设计
-> 变体
-> 颜色
-> 选择一套主题色
```

如果不是标准化制作，修改颜色通常会变成逐页、逐元素的重复劳动。

## 1.4 重新认识 PPT 模板

在很多人的印象里，PPT 模板就是别人已经设计好的一个 `.ppt` 或 `.pptx` 文件。使用者只需要把自己的内容填进去，就可以快速做出一份 PPT。

这种理解有一定道理，但不完整。因为很多下载来的模板只是“看起来像模板”，实际并不一定符合标准化主题模板的规则。

## 1.5 `.ppt` 和 `.pptx` 的区别

`.ppt` 是 PowerPoint 2003 及更早版本常用的文件扩展名。素材经常需要通过链接方式引用。

`.pptx` 是 PowerPoint 2007 以后常用的文件扩展名。它可以把更多资源嵌入到 PPT 文件内部，更适合现代 PPT 制作。

## 1.6 普通模板的三个常见问题

普通模板常见问题包括：

- 种类繁多，难以找到真正适合的模板
- 风格复杂，内容页适配度低
- 非标准化设计导致修改成本高

## 1.7 本节总结

本节课的核心是：不要只把模板理解为“别人做好的页面”，而要理解为一套可全局控制的设计系统。
