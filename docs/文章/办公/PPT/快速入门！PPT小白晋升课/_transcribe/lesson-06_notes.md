## 6. 制作主题模板导入大纲文档（实操课）

本节是前面内容的实操串联，从空白 PPT 开始制作主题模板，再把 Word 文档另存为 `RTF` 后导入 PPT，最终套用刚制作的主题版式。

### 6.1 实操目标

本节要完成的流程是：

```text
新建 PPT -> 定义主题字体和主题颜色 -> 设置参考线 -> 制作母版版式 -> 导入 RTF 大纲 -> 套用版式 -> 调整页面
```

这个流程把前面几节的知识连在一起：

- 主题字体
- 主题颜色
- 智能参考线
- 幻灯片母版
- 固定元素
- 占位符
- `RTF` 大纲导入
- 版式套用

### 6.2 定义主题字体

新建空白 PPT 后，先定义主题字体。

操作路径是：

```text
设计 -> 变体 -> 字体 -> 自定义字体
```

自定义主题字体时，一般设置两类字体：

- 西文字体
- 中文字体

课程中中文字体示例使用了微软雅黑。设置完成后，需要给这套主题字体命名并保存。

主题字体的意义在于：后续页面中的标题、正文、占位符文本都可以统一跟随主题字体变化，而不需要逐个文本框手动修改。

### 6.3 定义主题颜色

主题颜色可以通过 PowerPoint 自带入口设置，也可以借助 `iSlide` 色彩库快速选择现成配色。

课程中的做法是：

1. 打开 `iSlide` 色彩库
2. 选择一套推荐配色
3. 应用到全部页面
4. 如有需要，再进入 PowerPoint 的自定义颜色中微调

PowerPoint 入口大致是：

```text
设计 -> 变体 -> 颜色 -> 自定义颜色
```

主题颜色设置好后，后续形状、图表、文字强调色等元素都可以从主题色中取色。这样整体风格更统一，也方便后期一键替换颜色。

### 6.4 设置智能参考线

主题字体和主题颜色定义完成后，再设置参考线。

课程使用 `iSlide` 的智能参考线：

```text
iSlide -> 设计工具 -> 一键优化 -> 智能参考线
```

选择推荐的预设参考线后，页面会自动生成一套标准参考线。后续制作封面、目录、章节过渡页和内容页时，都围绕这套参考线进行布局。

参考线的作用是让页面有统一的边界和对齐规则。它不直接显示在最终放映中，但会影响页面是否整齐、专业。

### 6.5 制作母版中的固定元素

进入幻灯片母版视图后，先删除不需要的默认版式，再制作固定元素。

固定元素是指在多个页面中保持相同位置的元素，例如：

- 企业 Logo
- 页脚
- 页码
- 装饰线
- 固定背景元素

固定元素通常放在母版较高层级的位置，这样下面的多个版式都会继承它。

课程中使用 `iSlide` 图标库下载图标，并通过复制、组合和对齐，把它作为企业 Logo 的替代示例。随后使用参考线布局工具，把 Logo 对齐到参考线位置。

如果某一页不需要显示固定元素，可以在该页版式中勾选“隐藏背景图形”。

### 6.6 制作封面、目录和章节过渡页版式

封面页通常需要处理标题、副标题和视觉图片。课程中直接使用已有文本占位符，并调整字号、加粗、颜色和位置。

封面页制作时要注意：

- 标题要足够突出
- 文字颜色优先使用主题色
- 图片或插画要放在参考线限定的视觉区域内
- 不要把封面做成普通内容页

目录页的处理方式类似，先调整文本区域，再使用参考线布局工具对齐。右侧可以插入图片，作为视觉补充。

章节过渡页通常只承担章节切换功能，不需要太多内容。课程中使用文本区域和图片占位符，便于不同章节替换不同图片。

### 6.7 制作内容页版式

内容页是后续使用频率最高的版式，因此需要重点设计。

课程中的内容页版式包括：

- 标题占位符
- 正文文本占位符
- 内容展示区域
- 可替换的图片或图表区域

制作内容页时，先调整标题的字号、颜色和位置，再插入文本占位符作为正文内容区域。后续从大纲导入文字后，这些内容可以通过版式和重置功能快速适配。

### 6.8 导入 `RTF` 大纲文档

主题模板制作完成后，回到普通编辑视图，开始导入 Word 文档。

在 Word 中需要先完成标题分级：

- 一级标题设置为“标题 1”
- 二级标题设置为“标题 2”
- 三级标题设置为“标题 3”

然后按 `F12` 将 Word 文档另存为 `RTF` 格式。

回到 PPT 后导入：

```text
开始 -> 新建幻灯片 -> 幻灯片从大纲
```

选择刚刚保存的 `RTF` 文件，PPT 会自动生成多页幻灯片。

### 6.9 套用版式并二次调整

导入大纲后，生成的页面只是初始结构，还需要套用前面制作的版式。

常见处理方式：

- 封面页套用封面版式
- 目录页套用目录版式
- 章节页套用章节过渡页版式
- 普通内容页套用内容页版式

如果套用后发现位置不对，可以进行二次编辑。若发现母版版式本身有问题，可以回到幻灯片母版中修改版式，再回到普通页面点击“重置”，让页面重新应用新版式。

这也是母版的优势：不是每页单独改，而是修改版式后让相关页面继承变化。

### 6.10 内容页中的图示、图片和图表

课程后半段演示了几类内容页的快速处理方式。

图示类页面可以先用矩形框占位，再用 `iSlide` 的对齐工具和参考线布局工具进行排布。例如横向分布、扩展到参考线区域宽度等。

图片类页面可以使用 `iSlide` 插图库或图片库，快速下载并插入图片。如果需要圆形图片，可以先绘制圆形，再选中形状，通过图片库替换为图片。

图表类页面可以先用矩形作为位置占位，再插入图表。随后选中占位矩形和图表，通过 `iSlide` 的大小工具进行替换或匹配位置，最后删除不需要的占位矩形。

### 6.11 全局替换主题颜色和字体

当整套 PPT 初步完成后，可以再测试主题模板的全局修改能力。

如果要更换主题颜色，可以打开 `iSlide` 色彩库，选择另一套颜色并应用。依赖主题色的文字、形状、Logo 和其他元素会随之变化。

如果要更换主题字体，可以进入：

```text
设计 -> 变体 -> 字体 -> 自定义字体
```

修改中文字体和西文字体后，页面中的主题字体会同步变化。若某些页面没有立即更新，可以点击“重置”恢复到主题字体。

### 6.12 本节总结

本节完整演示了从空白文件到成品 PPT 的基础流程。

关键步骤包括：

- 先定义主题字体和主题颜色
- 再设置智能参考线
- 进入母版制作固定元素和页面版式
- 使用占位符预留文本、图片和图表区域
- 将 Word 文档另存为 `RTF`
- 在 PPT 中从大纲导入内容
- 为不同页面套用对应版式
- 通过重置和母版修改统一修正页面
- 最后测试主题颜色和主题字体的全局替换能力

这节课的重点不是把页面做得多精美，而是掌握一套可复用的制作流程。只要模板规则建立好，后续制作 PPT 时就可以在统一风格下快速生成页面。
