## 8. PPT 的基本作图操作（下）

### 8.1 本节核心

本节继续讲 PPT 基础作图，重点是 `Ctrl` 键、`Ctrl + Shift` 组合键，以及若干提高作图效率的功能。

本节重点包括：

- `Ctrl` 键的中心缩放和快速复制
- 三种复制方式
- `Ctrl + Shift` 组合使用
- 组合与解组
- 格式复制与粘贴
- 旋转和翻转
- 重复上一步操作
- iSlide 设计工具辅助排版

### 8.2 `Ctrl` 键的作用

`Ctrl` 键在基础作图中有两个常用作用：

- 以图形中心为基准缩放
- 快速拖动复制对象

当直接拖动图形控制点时，图形通常会以某个边角为基准放大或缩小。按住 `Ctrl` 后再缩放，图形会以自身中心点为基准向四周放大或向中心缩小。

如果同时按住 `Ctrl + Shift`，可以实现“以中心为基准的等比例缩放”。例如圆形会保持正圆，并以圆心为中心放大或缩小。

### 8.3 快速拖动复制

复制图形时，除了常规的复制粘贴，还可以按住 `Ctrl` 后拖动对象。这样可以直接复制出一个新对象，并把它放到需要的位置。

如果在拖动复制时同时按住 `Ctrl + Shift`，对象会沿水平或垂直方向复制，适合制作横向排列或纵向排列的图形。

常见用法包括：

- 横向复制多个按钮
- 纵向复制多个列表项
- 复制图标并保持对齐
- 快速搭建重复图形结构

### 8.4 三种复制方式

PPT 中常用复制方式有三种。

第一种是 `Ctrl + C` 和 `Ctrl + V`：

```text
选中对象 -> Ctrl + C -> Ctrl + V
```

这种方式最基础，但复制后通常还需要手动移动位置。

第二种是 `Ctrl` 拖动复制：

```text
选中对象 -> 按住 Ctrl -> 拖动对象
```

这种方式适合边复制边排版。

第三种是 `Ctrl + D`：

```text
选中对象 -> Ctrl + D
```

`Ctrl + D` 相当于复制并粘贴。它的特点是可以重复上一次复制后的位移关系。例如复制一个圆形并移动到右侧后，再继续按 `Ctrl + D`，后续圆形会按照同样的距离继续复制。

### 8.5 `Ctrl + Shift` 组合使用

`Ctrl + Shift` 经常用于把两个辅助键的作用叠加起来。

典型用法包括：

- 以中心为基准等比例缩放图形
- 沿水平或垂直方向拖动复制图形
- 保持对象排列方向稳定

例如绘制一个圆角矩形后，按住 `Ctrl + Shift` 拖动，可以快速复制出一组水平或垂直对齐的矩形。

### 8.6 组合与解组

当多个图形需要作为一个整体移动、缩放或排版时，需要使用组合。

组合快捷键：

```text
Ctrl + G
```

解组快捷键：

```text
Ctrl + Shift + G
```

组合后的对象可以整体移动和调整，适合处理已经搭建好的图示、流程图、图标组合或装饰元素。需要修改内部单个元素时，再使用解组。

也可以通过右键菜单完成组合和取消组合，但快捷键更适合高频操作。

### 8.7 复制和粘贴格式

如果已经调整好一个对象的格式，例如填充颜色、线条、阴影、字体、字号等，可以把格式复制到其他对象上。

常规方法是使用格式刷：

```text
选中已设置好的对象 -> 双击格式刷 -> 点击其他对象
```

更高效的方法是使用快捷键：

```text
Ctrl + Shift + C：复制格式
Ctrl + Shift + V：粘贴格式
```

这个方法不仅对形状有效，对文字也有效。例如可以先设置一个文字的字体、颜色、加粗和字号，再把这些格式快速粘贴到其他文字上。

### 8.8 旋转与翻转

旋转与翻转适合放到快速访问工具栏中，方便处理图形方向。

常用操作包括：

- 向左旋转
- 向右旋转
- 水平翻转
- 垂直翻转

设置方法：

```text
形状格式 -> 旋转 -> 右键 -> 添加到快速访问工具栏
```

加入快速访问工具栏后，选中对象即可直接点击对应旋转或翻转命令。

### 8.9 重复上一步操作

重复上一步操作可以显著减少重复劳动。

常用快捷键：

```text
F4
Ctrl + Y
```

在部分笔记本电脑上，`F4` 可能被系统功能占用，需要按 `Fn + F4` 才能触发。因此更推荐使用 `Ctrl + Y`。

适用场景包括：

- 给多个形状依次添加同样的边框
- 给多个文字依次设置相同字号
- 给多个对象重复同样的颜色设置
- 重复上一轮格式调整

例如先给第一个圆角矩形添加蓝色边框，再选中第二个圆角矩形按 `Ctrl + Y`，第二个对象会重复上一步操作。

### 8.10 iSlide 设计工具

iSlide 的设计工具可以辅助完成对齐、大小统一、参考线布局等操作，适合处理多个对象的批量排版。

常见功能包括：

- 等大小
- 顶端对齐
- 底端对齐
- 横向分布
- 纵向分布
- 对齐到参考线
- 扩展到参考线范围

使用“等大小”时，可以先选中需要调整的对象，再按住 `Shift` 选中目标对象，最后点击“等大小”。这样其他对象会统一到目标对象的大小。

这个方法对形状和图片都有效。

### 8.11 图片等比例裁切

调整图片大小时，如果直接拉伸，图片容易变形。正确处理方式是先调整图片框大小，再使用裁切中的“填充”恢复图片比例。

操作路径：

```text
选中图片 -> 图片格式 -> 裁切 -> 填充
```

进入填充后，可以拖动图片主体区域，选择最重要的画面部分。拖动时建议按住 `Shift`，避免产生不必要的偏移或变形。

### 8.12 本节总结

本节的核心是用快捷键和辅助工具提升 PPT 作图效率。

- `Ctrl` 用于中心缩放和快速复制。
- `Ctrl + Shift` 可以实现中心等比例缩放和水平/垂直复制。
- `Ctrl + G` 与 `Ctrl + Shift + G` 用于组合和解组。
- `Ctrl + Shift + C/V` 可以快速复制和粘贴格式。
- `Ctrl + Y` 可以重复上一步操作。
- iSlide 的设计工具适合统一大小、对齐对象、使用参考线进行快速排版。
